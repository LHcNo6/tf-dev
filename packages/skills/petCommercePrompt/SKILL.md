# 宠物带货提示词

把创意、商品资料或已有脚本写成可以拍出来、可以说出来的宠物带货短片。独立使用时交付文字；由工作流调用时接收其时长、模型能力、真实参考和已授权范围，返回内容供工作流写入节点。本技能不创建节点、不调用生成、不扩大生成次数或授权。

本技能是宠物带货任务的创作规则源；不再读取或套用 Lengyi，也不转入通用 workflow 的导演规则。外部 Skill 的参考职责、调度和声音方法已融入本文及附属资料，运行时无需另装这些 Skill。

## 1. 锁定输入与表演方式

沿用用户的宠物形象、商品事实、剧情、风格和台词。先区分已提供事实、允许创作的表演，以及影响执行的缺项；只补问无法推断且会改变结果的内容。已有定稿只修订本次要求的部分。

- **宠物主播**：带货且用户未指定表演方式时，按宠物模仿人类主播设计，可坐直、看镜头、用前爪示意、演示或在句末回应。保持物种、脸型、毛色和爪部形态；用姿态与行为表达拟人程度。需要站立、服装、握持工具或更强拟人化时写明设定，并使资产图支持该动作；用户指定自然动物、旁白或无声时按其要求。
- **商品事实**：品牌、型号、外观、功能、价格、优惠和购买入口只来自用户或可核实资料。用实际展示支撑卖点，不补造功效、评价、销量、库存或适用承诺。只有概念商品时明确为虚构方案。带货请求缺商品资料时先给可独立完成的创意结构，具体卖点及最终商品提示词待补。
- **无商品分支**：调用方明确不启用商品时，保留宠物表演与镜头方法，省略商品卖点和销售引导，不为完成模板创造商品。
- **能力**：模型未确定时可写通用草稿并标明待核实项。最终执行稿以工作流提供的真实时长、参考模式和声音能力为准；品牌、模型名称不能证明具备多镜头、中文语音、口型同步或参考音频能力。

## 2. 先排口播，再安排镜头

默认规划 20–30 秒，用户或调用方已指定时长则沿用；本技能的短片方案上限 30 秒，超过时说明需要相应长视频工作流。按钩子、商品展示、可见演示和收尾组织内容，可合并或省略不需要的节拍。开场直接进入宠物的表演或问题，不固定先拍环境全景；镜头数量由信息量、动作及口播长度决定。

先写能自然说完的台词，给吸气、动作和句末停顿留出时间，再分配连续镜头区间，末镜结束时间等于总时长。朗读估算只用于发现拥挤，不当作模型保证；已有音频用实际时长。台词过长时减少口头修饰、分配更多时间，涉及用户定稿或硬时长冲突时说明并核对，避免靠加速吞字填满。

每镜有一个明确展示重点和主要动作，按“起始状态 → 动作过程 → 可见终态”写细节。口播、商品接触、复杂机位同时竞争时，优先保持说话和商品可读性，减小动作或拆分镜头；固定机位和稳定光线都是有效选择。切镜用于增加信息，不给镜头数、每镜运镜或环境运动设硬性指标。

写完整逐镜提示词或修订动作、口播、商品交互时，读取 [逐镜写法与示例](references/shotGuide.md)。先完成各镜的动作与声音，再合并成一条完整视频提示词；不要只交付一句概括或让工作流自行补全镜头。

## 3. 资产与参考职责

按需要交付宠物、商品和场景的资产提示词；已有合适素材时优先复用并注明来源，不要求再次生成。宠物参考明确固定外观、拟人姿态、必要服装和可见前爪；场景参考交代桌面、商品陈列区域和光线，避免带入重复宠物。商品实图作为形态依据，包装结构、颜色、图案和已有文字保持一致；需要新角度、看不见的背面或内部结构时说明证据缺口，不能把生成补全当作真实商品资料。

每个参考只分配清楚的职责：宠物身份、商品外观、空间或实际起始构图。独立宠物图加商品图不等于已确定二者的接触姿态，文字需写清位置和接触；精确姿态依赖额外画面时标为需要的资产，不声称已经存在。新增素材需求交回工作流核对预算和能力。

规划稿使用清楚的资产名和来源；执行稿由工作流按实际输入映射引用标签，例如 `{{ref N}}`。保留资产名与职责供映射核对，最终生成前不留未解析引用、不凭计划顺序猜编号。图生视频重点写动作和变化，保留必要身份约束；参考图已确定的外观不反复重新设计。

## 4. 口播与声音

带货默认由宠物在画内面对镜头说中文，声音按其人设设计并跨镜一致；用户指定语言、声音或画外配音时沿用。对每条台词写明说话者、原文、时间、语气和停顿，以及说话前、说话中和说完后的可见动作。用“声音”区块分别交代对白、环境声、动作音效和音乐；是否配乐按用户或调用方选择，未指定时不主动加背景音乐，保留需要的对白及环境声。

画内口播写清嘴部随台词自然开合、句末闭嘴、其他角色保持安静；保留动物口鼻结构，不把随机张嘴或后期旁白称作已实现对口型。画外配音明确不驱动宠物张嘴。已有口播音频时指定其为唯一台词来源和声音/节奏依据，按实际接口映射音频；文字台词单独留在审阅稿，最终音频驱动稿引用音轨并避免叠加第二套生成对白。

执行接口明确不支持所需原生声音或音轨输入时，说明具体冲突并交回工作流处理。中文语音、口型或镜头时间等表现效果缺少资料时，保留用户要求和提示词，标明效果未经验证，由工作流在授权范围内尝试；不把未知写成不支持或质量保证。不静默改成无声片或画外旁白，不假定当前画布已有配音/对口型工具。

## 5. 交付与核对

交付的详细程度跟随请求。完整带货方案包含：

1. **脚本总览**：目标总时长、人设和拟人程度、已知商品事实、各镜展示重点及口播时间表；缺项与假设分开标明。
2. **资产方案**：真实素材及职责、缺失必要资产的完整图片提示词；商品概念稿与实物参考区分清楚。
3. **完整视频提示词**：全片身份/商品/场景约束、参考职责、连续逐镜正文、对白与声音；模型参数放在提示词外，确需时间块时正文保留时间区间。具体格式参考 shotGuide，按真实接口适配，不强套通用 workflow 的外壳。
4. **验收重点**：列出本片最可能出错的宠物身份/肢体、商品外观/接触、台词/声音归属、口型和镜头衔接问题。验收描述观察对象，不承诺模型一定服从。

交付前核对：镜头时间连续且总长正确；每镜都有可执行动作和终态；台词留足时间；宠物身份、前爪和商品位置跨镜连续；卖点有来源且演示没有夸大；真实引用和声音方案与能力一致。给出完整修订稿，并简述变化，避免把零散补丁交给调用方自行拼接。未实际生成、观看或听过的内容如实标记。
