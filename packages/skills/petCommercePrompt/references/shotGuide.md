# 宠物主播逐镜提示词

写镜头时先确定身体和商品如何接触，再确定摄影机如何看见它。以下是规划字段，不要求把机械表格直接塞进生成 prompt；最终按时间顺序写成可读的镜头段落。

## 镜头中要说清楚的事

| 项目 | 写清什么 | 过于笼统的写法 |
| --- | --- | --- |
| 时间和重点 | 起止时间、本镜让观众看懂的商品信息；展示目的放脚本总览，生成正文写可见事件 | 展示商品，很吸引人 |
| 起始状态 | 宠物姿态、面向、视线、前爪支撑点，商品位置、角度及与宠物的距离关系 | 猫在桌子后 |
| 表演 | 眼神先落到哪里，耳朵/头部如何反应，前爪怎么模仿主播，何时停顿；选与台词有关的少量细节 | 可爱、自信、专业带货 |
| 接触和动作 | 哪只爪碰哪个部位、从哪里移到哪里、移动方向和停止点；一镜解决一个展示任务 | 拿起来展示一下 |
| 摄影和光线 | 景别、视角、主体在画面的位置、焦点、固定或一个有理由的运动；保留同场景主光方向 | 电影级运镜，光影高级 |
| 台词 | 说话宠物及可辨识外观、逐字原文、开始结束时间、音色/语气、停顿和说话时动作 | 宠物介绍产品优点 |
| 终态和衔接 | 商品最终位置、爪子落点、视线、闭嘴停顿；下一镜从同一状态或明确切到新视角 | 然后切下一镜 |

“前爪抬起 → 示意瓶身 → 回到桌面”可以是一个手势，细节用于约束过程。开盖、倒出、换爪、举到镜头前同时说长句则有多个相互依赖的目标，需要简化或拆开。商品可以放在支架上由宠物示意；若必须握持，让参考姿态和爪部结构支持握持，保留商品重心、承托与接触。不要为了规避难度删掉用户明确要的演示，应先解释冲突并给出可选拍法。

## 视频正文的推荐组织

```text
全片设定：宠物身份和拟人表演方式；同一场景、主光方向和声音人设。
参考职责：实际宠物参考控制身份；商品参考控制真实商品外观；场景参考控制空间。
保持：本片必要的身份、商品和空间约束。

镜头1【起点–终点】
画面：起始姿态与商品位置 → 本镜主要动作 → 结束构图；景别、机位/运动、焦点与光线。
口播：可识别的说话者；台词“……”；说话区间、语气、停顿和嘴部动作。
声音：本镜需要的环境声或接触声，与全片音乐约定一致。

镜头2【……】
……
```

全片重复约束集中写；各镜补本镜动作和必须保持的关键状态。无口播镜头标明本镜安静；不要用“同上”“省略”“自行补充”代替完整提示词。原生多镜头或时间控制不支持时，这是待适配的拍摄计划，不能声称已能按该配置生成；将冲突交回工作流，保留用户规格。

## 示例：橘猫主播介绍不倒翁猫玩具

这是写法示例，不是经过生成验证的成片。假定用户已提供：橘猫照片、玩具商品实图、允许使用的卖点“轻推会摇晃”，以及 24 秒、中文画内口播、不配乐的要求。玩具尺寸、颜色、图案及真实包装只取商品图；示例不提供价格、材质或其他未确认功效。声音和多参考能力由工作流另行核实。

### 脚本与资产

| 时间 | 重点 | 逐字台词及说话区间 |
| --- | --- | --- |
| 0–6 秒 | 猫主播直接打招呼并示意商品 | 0.8–4.8 秒：“家人们，今天轮到本喵当主播。” |
| 6–12 秒 | 展示一次前爪轻推及玩具摇晃 | 6.8–10.2 秒：“轻轻推一下，它就摇起来啦。” |
| 12–18 秒 | 留出时间看清玩具动作，猫做无声反应 | 无台词 |
| 18–24 秒 | 回到主播和商品同框，结束引导 | 18.8–22.2 秒：“想看看细节，就去商品页瞧瞧。” |

宠物照片和商品实图直接复用。若需要补宠物姿态参考，可写“同一只橘猫，保持照片中的脸型和毛色分区，坐直，正面，胸部以上及两只前爪完整入画，两只前爪自然分开支撑，简洁背景”，以真实照片为身份依据，不重新设计脸型。场景图提示词写“明亮的室内直播桌面，哑光浅色桌面，桌后留出一只猫坐直的空间，商品陈列区在画面右侧，背景简洁，柔和主光从画面左侧窗户照入，画面中没有宠物、人物或商品”。这些是资产计划，不表示图片已经生成。

### 一条完整视频提示词示例

下文使用“宠物参考”“商品参考”“场景参考”作为规划名称；进入节点前须替换为已核实的实际引用并重新核对映射。

```text
一只橘猫模仿直播间主播介绍桌上的不倒翁猫玩具。橘猫身份依据宠物参考，保持脸型、耳朵、毛色分区和猫爪形态；它坐直在桌后，用前爪做少量主播手势，始终保持猫的口鼻结构。玩具外观以商品参考为准，保持其轮廓、比例、颜色、图案和部件数量，只有这一个玩具。空间依据场景参考，玩具位于画面右侧、橘猫左前爪前方，柔和窗光始终从画面左侧照入，宠物和商品保持清楚可辨。
声音设定：橘猫是唯一说话者，明亮、轻快的中文中性声音，三次口播音色一致，像面对观众聊天，句间留自然停顿。台词按原文说完；说话时嘴部与声音配合，保留猫口鼻形态，句末闭嘴。无背景音乐，保留轻微室内环境声和必要接触声。

镜头1【0–6秒】
中近景，平视，固定机位。橘猫位于画面偏左，玩具完整直立在右侧桌面，两只前爪最初都搭在桌边。它先看向镜头，左前爪抬起朝玩具做一次示意，爪子不挡住玩具正面，然后放回桌面；身体保持坐直，主光在左侧脸颊和玩具上留下柔和亮面。橘猫在0.8–4.8秒轻快地说：“家人们，今天轮到本喵当主播。”句末小幅点头，闭嘴，眼睛转向玩具，最后保持两爪落在桌面、玩具直立的状态。

镜头2【6–12秒】
切到稍低的桌面中景，橘猫仍在左侧、玩具仍在右侧，能看清左前爪和玩具底部，主光方向不变，固定机位。起始时玩具直立。橘猫的左前爪从桌面抬起，轻触玩具朝猫这一侧的中部，沿画面向右轻推一次，随即收回原落点；玩具底部保持接触桌面，围绕底部来回摇晃，摆幅逐渐减小。橘猫看着玩具，在6.8–10.2秒说：“轻轻推一下，它就摇起来啦。”之后闭嘴，左前爪停在桌面，玩具继续小幅摇晃，不再次推动。

镜头3【12–18秒】
切近玩具和猫左前爪的同框近景，玩具居中，爪子留在画面左缘，固定机位，对焦玩具轮廓和底部接触面。承接上一镜的细微摇晃，摆幅继续减小，最终停稳直立；橘猫不伸爪追打，画面上方只露出它微微倾向玩具的头部和注视玩具的眼睛，句末反应由眨眼表达。本镜无台词，猫保持闭嘴，只有轻微室内底噪以及与真实接触相符的轻声，结尾玩具停稳、猫爪位置不变。

镜头4【18–24秒】
切回第一镜的平视中近景和相同构图，玩具已直立停稳，橘猫坐直，两只前爪搭在桌面。它从玩具移回视线与镜头对视，在18.8–22.2秒用同一声音说：“想看看细节，就去商品页瞧瞧。”同时左前爪向玩具做一个小幅示意，随后落回桌面。说完闭嘴，保持猫与商品同框到24秒。结尾没有新增道具或包装；不添加未提供的促销字样或人物声音。
```

示例验收重点：同一只猫及同一件商品；左前爪只推动一次且接触可见；摇晃跨镜延续并逐渐停止；三条台词正确、唯一说话者、口型和句末停顿可检查。若模型无法完成，不以换一套形容词代替定位问题；区分动作、商品一致性和声音失败后再修改相应部分。

## 方法来源

本技能将以下方法重新组织为宠物带货规则，未照搬供应商参数或生成效果承诺，运行时不依赖这些链接：

- [Square-Zero video-prompting](https://github.com/Square-Zero-Labs/video-prompting-skill)：参考职责、起始状态、按时间推进的动作与声音、明确终态。
- [Cinematic Director](https://github.com/wuwangzhang1216/DirectorSKILL)：先调度后取景、可见表演、商品展示与有针对性的连续性约束。
- ai-pet-short-video-director：物种与外观一致、爪子/视线/道具接触，以及画面因果；其自然动物倾向在此按明确的拟人主播需求调整。
- [dexhunter Seedance Skill](https://github.com/dexhunter/seedance2-skill)：宠物对话表演示例。所有能力要求由实际工作流核实。
