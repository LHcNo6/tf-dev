# 宠物带货短视频制作（30 秒内）

从用户的创意、剧情或商品卖点制作一条不超过 30 秒的视频。只问无法合理推断且阻碍执行的信息；本流程不进入长篇 workflow 的分阶段确认或 Seedance 路由。用户明确只要文字时不操作画布。

## 模式与开头授权

开始制作时询问交互模式或自动模式；用户已明确选择则不重复问。交互模式按下文原有具体方案确认执行。自动模式先集中确认目标、视频时长/画幅/分辨率/声音及必要图片规格、图片和视频的供应商与模型或有序候选、总生成调用上限（初次及重试均计入）和每个生成对象的失败重试上限（可为0）。说明具体创作和完整提示词将在授权后形成，费用不可查询时说明算力消耗未知；表现效果未知时说明将按目标尝试、结果需验收，不附加“资料无法核实就暂停”的条件。取得用户对上述范围和自动生成的明确同意，缺项集中补齐。跳过、取消或未回答不授权。仅本次任务有效。

自动模式在授权范围内自行确定剧本、提示词及实际节点方案，不逐阶段询问；按候选顺序选择实际可用且满足执行参数和参考输入要求的模型。生成前核对实际方案与授权、检查所有计划初次调用可在剩余总次数内完成，并记录每个对象及其尝试次数；每次调用前再核对模型、参数、提示词、真实参考、剩余总次数和该对象的重试余量。所有生成尝试（包括明确失败的尝试）均计入总次数；仅本次明确失败且总次数、该对象重试余量及尚未开始对象的初次调用预算均足够时重试。运行中、取消、等待超时、启动结果或状态不明不得重试；超出范围、缺少必要素材、执行能力明确不支持或真实素材依赖不可核实时暂停并保留成果。表现质量未知按下方声音规则继续尝试，不作为素材依赖不明。用户中途修改导致实际内容或依赖不明、超出授权时暂停，不把修改当作自动授权。允许自动使用本次成功且可读取的输出作为计划内下游输入，但不声称用户已审阅或采用。画布须保持打开，关闭或切换后不保证续跑。

## 1. 创作与资产

按本次目标视频模型选择创作链：用户明确指定或节点实际选中 **Seedance 2.5** 时使用 `petCommercePromptSd25` 完成创作和最终提示词；其他模型使用 `petCommercePrompt` 形成创作方案，再由 `videoPromptAdapter` 根据确切模型和输入模式整理最终提示词。用户给出有序模型候选时，先按自动模式授权及实际能力选择模型，再选对应规则；不得仅因技能版本改变供应商或型号。

通过 `skillOperator(action=list)` 查找所选技能及其 scope，再以返回的 name 和 scope 读取主文件；编写完整逐镜提示词时，使用同一 name、scope 读取 `path=references/shotGuide.md`。非 Seedance 2.5 还须查找并读取 `videoPromptAdapter`，由其按实际模型和输入模式统一选择官方、第三方 `videoPrompting` 或通用规则；使用第三方时按适配器要求读取其真实 scope 与专篇。保持身份、商品、逐字台词、素材和动作；通用回退标明未核实。没有 skillOperator 时按本轮技能目录中的实际位置读取。所选宠物技能负责拟人表演、商品展示、逐镜动作和口播；不叠加 Lengyi 或通用 workflow 导演模板。传入用户意图、时长、真实素材及职责、已知模型能力和本次授权范围，取得完整脚本、资产提示词和一条最终视频提示词。所选宠物技能、适配器主文件或必需逐镜资料确实不可读取时说明缺项，暂停依赖的创作与生成。

开始时模型尚未确定，可用通用宠物技能形成明确标记为暂定的创意和画布草稿；实际模型确定后、任何媒体生成及交互模式具体方案授权前，重新按上述规则读取对应技能，完成脚本、资产和完整视频提示词并写入本次节点。自动模式在开头授权范围内记录最终方案并核对预算。后续模型改变导致创作技能或提示词变化时，重新规划受影响内容；交互模式展示差异并重新取得受影响调用授权，自动模式核对原授权范围和依赖，超出或不明时暂停。保留用户已有节点和成果。

用户提供商品或卖点视为启用商品；明确不使用商品时将该条件传给创作技能，省略商品内容。剧本默认 20–30 秒，用户指定更短时按其要求，超过 30 秒说明上限；计划有时间区间时连续且与剧本总时长一致，Seedance 2.5 按其专用技能使用阶段或所需时间区间。视频生成时长必须与最终剧本总时长一致，例如剧本 24 秒就设置为 24 秒，不采用节点自身默认时长。最终执行稿匹配已知的参数和参考输入限制；表现能力未知时保留目标并标记未验证，不以模型名称断言支持或不支持。

已有图片直接作为对应素材；用户要上传时先创建节点并请其在对应节点上传，等待上传完成后再规划调用。没有可访问的图片时不能用文件名或描述冒充图片。可使用已有画布中的适用图片输出，但不要覆盖原素材或改动无关节点。

## 2. 搭建画布

只用本轮实际可用的画布工具。读取当前画布和可用节点类型，按实际返回的类型创建一个文本节点、三个图片生成节点（命名为“宠物主角”“商品（可选）”“场景”）和一个视频生成节点，排在不遮挡已有内容的位置。先通过 `getNodeTools` 查函数及参数，用 `node:setText` 写脚本总览，用 `node:setPrompt` 写资产提示词与完整视频提示词。不要把文本节点连接到生成节点：相连文本会被追加进提示词。

图片生成节点支持用户手动上传。若用户给出工作区已有图片但生成节点不提供导入函数，使用该节点的上传入口；不得伪造 `node:setImage` 或写画布 JSON。核对节点 `outputs`，已有输出的节点不生图。商品未启用时保留空商品节点且不连接；其他资产有实际输出后读取端口并连接到视频节点。若素材已经在其他节点且用户指定复用，将其真实输出连接到视频节点；保留对应的三个默认节点。

## 3. 方案与一次授权

通过 `getNodeTools` 查看 `node:getConfig` schema；选模型或查替代方案时，支持 `includeModels` 的节点用 `{includeModels:true}` 查询完整目录，旧插件按实际 schema 查询。日常复核用空参数读取 `config` 和 `selectedModel`，视频还要读 `matchingModes`；旧插件按返回目录核实。所选模型不存在时暂停，不猜测能力。

通过各生成节点的 `node:getConfig` 查询实际可用模型。图片未指定模型时遵守宿主对模型选择的要求。视频分辨率默认 `480p`，用户明确指定其他分辨率时按其要求；视频时长取最终剧本总时长。视频选可接收全部启用图片的多参考模式，且 `durationResolutionMap` 同时支持该剧本时长与所选分辨率；不要把三张图当首尾帧。模型或模式缺失，或不支持该时长和分辨率组合时，说明缺少的能力并保留画布，请用户选择受支持的方案；不静默更改剧本、时长、分辨率、参考或用户明确指定的模型。

视频配置需要实际输入才能选择匹配模式；生图前根据返回的模型声明确定可行方案，素材就绪后连接、按实际 `matchingModes` 设置并核对。显式将视频的 `duration` 设置为剧本总时长、`resolution` 设置为所选分辨率，并在调用前核对这两个值；图片规格单独选择。用户明确指定图片或视频模型时优先使用，其他配置从实际能力中选有效值；交互模式在授权前展示，自动模式须符合开头授权范围。用户请求超过模型能力时停下并说明。

交互模式在具体方案授权前说明画内说话或画外配音、逐字台词、声音人设和实际生成方式；自动模式在调用前记录这些内容并核对开头授权。用实际节点配置和可用模型声明核对原生声音开关、参考输入及其他执行参数；可设置的声音参数按真实 schema 写入并读回。中文口播、口型同步、逐镜时间控制等表现效果即使缺少供应商资料或联网查询失败，也不等于不支持：保留原目标与提示词，在已授权范围内直接生成，不为此再次询问或要求用户提供证明；记录效果未经验证，交付时按实际审片结果说明，不承诺准确。只有接口或可靠能力声明明确不支持所需声音、参考或其他执行条件时才暂停并说明；不静默改成旁白、无声或假定已有后期配音工具。用户已经明确确认支持并要求生成时，按其确认继续尝试，但不把用户确认当成供应商证明或成片质量保证。

交互模式在任何媒体生成前，一次展示具体方案：每个待生成资产及次数、图片模型和规格、完整资产提示词；视频模型、时长、比例、分辨率、声音、完整视频提示词、每个参考的节点和用途、视频次数。已上传素材列出真实来源；待生成素材标明是该指定节点的本次输出。总次数为每个缺失且启用的必要资产各一次，加视频一次；费用有可靠报价才展示，否则标明算力消耗未知。用宿主现有确认方式取得明确同意；跳过、取消或无回答都不启动。批准后同一方案不再逐项询问。自动模式按开头范围授权执行，调用前记录完整方案并核对范围，不要求另行批准具体提示词。

## 4. 执行与交付

授权后先重新读取节点、提示词、配置和已有输出；若用户在等待时修改了会影响调用的内容，核对授权；交互模式展示差异并确认，自动模式遇到范围或依赖不明时暂停。并行启动无需互相依赖的缺失图片，调用每个节点实际的 `node:generateImage`，保存返回的 `attemptId` 和 `startedAt`。按实际 schema 调用 `node:waitGeneration({attemptId})`，由画布工具内部连续等待：图片从生成启动计时，第5分钟检查本次调用记录一次，再等最多2.5分钟；视频第10分钟检查一次，再等最多5分钟。完成或失败立即返回，期间无需每30秒再次请求模型。`waitBudgetExceeded` 表示任务仍运行、仅结束等待；报告待续，保留任务，不自动再次等待、取消或重生成。稍后继续先查询原生成编号的状态。旧插件无生成元信息时按其真实单次等待合约操作并说明限制。保持画布打开；调用取消、节点卸载或无法取得状态时停止依赖链并报告。明确失败时交互模式停止，自动模式按开头授权重试规则处理；保留已完成成果。

全部所需素材成功后重新读取输出和入边，检查引用顺序及类型；若用户替换或修改了已授权素材、提示词或配置，先核对范围及依赖；交互模式展示差异并重新取得受影响调用的授权，自动模式超出授权或依赖不明时暂停。`{{ref N}}` 按视频节点真实输入顺序及其 `referenceOrder` 映射，不能猜编号。设置匹配的多参考模式并再次核对规格、完整提示词与参考，然后调用 `node:generateVideo` 并等待终态；自动模式的失败重试受开头上限约束。旧输出或 idle 不能证明本次成功；只有本次 succeeded 和实际输出可以作为生成结果。

已生成不等于已检查或用户已采用。报告视频节点和实际可用的文件路径，说明未能检视的画面或声音；让用户在节点播放或下载。失败时指出具体节点和原因，不删除脚本、资产或已有输出。用户稍后继续时先读取画布和状态，避免重复创建、重复生成和误用旧输出；关闭页面或切换画布后的续跑不作保证。
