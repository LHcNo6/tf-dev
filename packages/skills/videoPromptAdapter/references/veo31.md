# Veo 3.1 提示词适配

核对日期 2026-11-11：[Google Cloud 视频生成提示指南](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/video-gen-prompt-guide?hl=zh-cn)；该指南面向 Veo 系列，并非对全部 Veo 3.1 供应商和输入方式的兼容性保证。对应版本、文生/图生/首尾帧、声音与参数以当前节点声明为准。

依据画面需要用自然语言写具体主体、场景、动作及顺序、合适的镜头、风格与光线，不强制填满摄影词。文生视频描述起始画面；图生视频尊重图片已确定的画面，着重描述动作、视线及镜头变化；首尾帧或参考素材仅在接口确实支持且绑定后说明角色。音频使用独立句子说明对白、环境声或音效：逐字写说话者与台词，分别区分画内与画外声音。实际有反向提示字段时才考虑将不希望出现的元素写入该字段；未暴露该字段时不虚构参数。官网指出部分高级镜头的结果和可靠性有差异，时间、商品文字与动物口型均需验收。

示意：`平视中景，一只橘猫坐在桌后，玩具直立在前爪旁。猫看向镜头，轻快地用中文说：“轻轻推一下，它就摇起来啦。”说完闭嘴，左前爪轻触玩具并轻推一次，玩具在桌面上摇晃后停稳。柔和窗光从左侧照入。声音：猫是唯一说话者，轻微室内环境声。` 示例非实测；真实参考和台词应替换为本次素材及已确认内容。
