# 宠物带货创作规划

短片或长片均可使用；此文件只产生创意与分镜输入，不调用生成、不规定单段模型时长或最终 prompt 外壳。保留用户的宠物、商品、剧情、逐字台词和素材；可以代写口播时才基于已确认事实创作。品牌、规格、功效、价格、促销和评价须有用户提供或可核实的依据；缺项标明，不推测。用户未要求带货则不强加商品。

明确目标受众、主播性格、拟人程度、真实素材来源与职责、商品展示目标和声音人设。默认拟人主播保留动物脸型、口鼻和爪部，用姿态、目光、动作与声音模仿人；用户选择自然动物、旁白或无声时遵从。已有宠物或商品图优先复用，不用生成的未知结构充当真实商品资料。

为全片列出叙事节拍与每段初态、终态、时长、镜头重点、资产和声音。每镜依据需要描述起始姿态、视线、前爪支撑、商品位置和角度；写主要动作的方向、接触点与终态，再决定景别、机位、焦点、光线。让动作和商品卖点形成可见因果，避免空泛形容词或无目的运镜。对每句写说话者、逐字台词、画内/画外、时间预算、音色、语气与停顿；短句尽量安排在正面、口鼻无遮挡的画面。动作过密时安排时间或提出拆段，不删除用户要求。

长视频建立跨段连续记录：宠物身份和声音、场景与光向、商品外观和位置、爪子/视线及道具状态、各段台词和前后动作。区分计划内上一段尾帧与已经生成且可读取的真实尾帧。下一段需要同时使用尾帧和其他参考时，交由工作流核对实际绑定；当前绑定冲突时不丢弃参考或伪造句柄。提示词模板和最终素材绑定由对应工作流完成。

方法来源：Cinematic Director（MIT）强调调度、可见动作及连续性；ai-media-generator（MIT）提供商品与 UGC 的组织角度；Square-Zero-Labs/video-prompting（Apache 2.0）提供参考职责及模型分篇的思路。本文件为独立归纳，不包含三者的原文模板；模型能力和成片表现以实际接口及生成验收为准。
