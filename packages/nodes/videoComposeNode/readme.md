# 合成视频

连接多个视频节点或上传视频，在片段列表中调整顺序与起止时间。合成结果以第一个片段的尺寸为画幅，其他片段等比缩放并补黑边，输出 H.264/AAC MP4；无音轨的片段自动补静音。

可上传背景音频，选择混合原声或替换原声并调整音量；音频从成片开始播放，短音频结束后补静音，长音频截断。可上传 UTF-8 SRT 或 ASS 字幕，选择烧录或可关闭字幕轨；MP4 字幕轨会转换为 mov_text，ASS 的复杂样式可能丢失。字幕时间以完整成片为准。

合成需要宿主配置可用的 FFmpeg、FFprobe、libx264 和 AAC 编码器；烧录额外需要 subtitles 滤镜。缺少烧录滤镜时可改选字幕轨，或配置支持该滤镜的 FFmpeg。处理可取消；成功结果作为视频端口输出并保留在节点文件目录。选中节点后可通过上方工具栏下载结果或全屏播放；没有结果时下载按钮不可用。
