# 已安装第三方 Skill 的入口译本

本目录保存用户明确要求整理的 3 个已安装 Skill 的中英文入口，不作为新的重复技能扫描，也不自动安装或覆盖第三方包。9 个内置技能的译本在 `packages/skills/`。

| 技术 name | 本目录 | 中文展示名 |
| --- | --- | --- |
| `seedance` | `seedance/` | Seedance 视频与图片提示词 |
| `sd25-pe` | `sd25Pe/` | Seedance 2.5 提示词优化 |
| `lengyi-seedance25-prompt` | `lengyiSeedance25Prompt/` | Seedance 2.5 连续镜头提示词 |

2026-11-13 以当前数据目录内已安装入口为依据整理。中文 `zh.md` 对应目标包的 `SKILL.md`，英文 `en.md` 对应目标包同目录的 `en.md`；中文入口声明 `metadata.locales.en: en.md`。两者保持原技术 name，中文与英文默认交付语言不同，用户指定语言、逐字对白、引用标签及模型固定语法优先。译本将重复说明合并整理，不把第三方能力描述当成本平台实测结果。

服务构建将本目录复制到 `build/skillLocales/`。部署已有第三方技能时，先备份并核对已安装的原入口及版本，再将本目录两份文件按上述映射合并进对应原包；保留原包全部参考资料、许可证、示例和其他文件。不要把仅含入口译本的目录作为完整第三方技能安装，否则可能丢失其依赖资料。没有安装原包时应先取得并安装对应来源包，再合并译本。

本机已经按此映射同步到 `data/skills/`，原入口保存在 `data/skillBackups/skillLocalization20261113/`。可通过现有插件“导出分享”得到含中英文入口与原参考资料的完整 ZIP，再导入其他部署；不要只导出单份入口。

`sd25-pe` 原版包含每会话首次尽力更新的固定命令，译本保留该行为和失败继续分支。上游更新可能覆盖本地入口或语言声明，更新后须重新核对译本与上游版本；服务不会未经核对强制覆盖用户文件。参考资料和许可证保留原语言，本目录不声称完成全部附属资料翻译。
