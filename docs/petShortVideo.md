# 宠物短视频工作流维护说明

## 使用与行为

在项目中打开画布，向 Agent 描述 30 秒以内的宠物带货视频，或明确指定“宠物短视频工作流”。工作流依照内置 Lengyi 规则生成脚本、资产提示词与一条视频提示词，创建文本、宠物主角、商品、场景和视频生成节点。商品节点始终创建，但只有启用且素材就绪时才作为视频参考；用户可在图片生成节点上传素材。生成前一次展示方案并确认算力消耗，批准后依次准备缺失图片并生成视频。

视频默认使用 480p，用户明确指定其他分辨率时按其要求；视频生成时长与最终剧本总时长一致。工作流使用实际节点端口、输出、参考顺序及模型能力；模型不支持所需参考数量、剧本时长和所选分辨率时保留画布并说明，不静默修改。生成失败或取消不自动重试。任务依赖打开的画布和节点，不保证关闭、切换后后台续跑。模型、素材或提示词在授权后发生变化时，受影响调用须重新核对授权。

## 实现与安装

- `packages/skills/petShortVideo/` 包含工作流和 Lengyi 提示词规则快照及模板。Agent 默认提示词将明确的宠物带货短片路由到该工作流，其他视频制作仍使用原工作流。
- 图片和视频生成节点复用 `useNodeGeneration` 的 `node:waitGeneration`，单次等待最多 30 秒，超时返回当前状态；调用取消或节点卸载结束等待，不代替取消生成。状态只对应本次打开节点的生成，旧输出和 `idle` 不能证明本次成功。
- 已初始化的数据目录缺少 `petShortVideo` 时，服务启动时补装；存在同名目录时保留现有内容。后续源码修改不覆盖已经安装的同名 Skill，须使用现有插件安装或编辑流程更新。
- 提示词和素材经画布节点工具写入；节点工具在画布挂载期间可用。等待前后需要核对生成状态和参考，不将当前节点状态作为可跨会话恢复的任务记录。
