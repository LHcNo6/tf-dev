## 第二批：宠物 IP 与剧情素材

新增三视图、四格表情、动作定格、主题换装、双宠互动、场景设定、剧情关键帧和四格漫画。三视图及多格图均为一张合成设计稿，不自动拆图或批量生成。三视图没有参考的背面只作设计推演；要求准确还原时先补齐视角。四格表情默认按阅读顺序呈现开心、委屈、惊讶、嫌弃，与已有单张贴纸分开。

本批按用户确认先交付指令，8 张配图暂缓；新增卡片使用现有分类图标，首批 24 张预览保持原样。

动作定格缺少动作、主题换装缺少主题、双宠互动缺少任一宠物参考或互动要求、场景设定缺少场景描述、关键帧缺少事件或关键角色参考、漫画缺少四格情节时，提示词要求先补齐。双宠分别绑定 A/B 身份；场景默认仅画环境；漫画只有用户提供确切对白时才排字。以上由 Agent 按提示词执行，目录没有新增结构化表单或强制校验接口，也不保证模型精确遵守。

## 第三批：图片编辑与修图

新增清理杂物、更换背景、扩图补边、局部换色、照片修复和参考画风，均归入通用范围的「图片编辑」分类，使用照片编辑图标。按用户已定范围继续暂缓配图，本批没有调用图片生成或编辑服务。

除扩图按用户目标画幅外，默认沿用原图比例，参考画风沿用主体图比例；规格须匹配实际模型能力。缺少原图、删除对象、目标背景、扩图比例、换色对象或颜色时，相关提示词要求先补齐；参考画风须分清主体图与画风图。照片修复保留原貌，黑白照片不默认上色；商品换色仅作设计预览；画外补齐、遮挡区域及未知颜色属于推演，不作为真实信息。

全部指令要求以一张新图交付并保留原图，不自动追加尝试。此处提供基于参考图的语义编辑提示词，没有新增选区涂抹、mask 或像素级锁定能力，未修改区域不承诺逐像素保持。缺参考先询问等行为由 Agent 按提示词执行，没有新增结构化入参校验。

## 第四批：宠物商品与活动图文

新增商品卖点图、活动海报、尺寸示意图、使用步骤图和商品对比图，复用「宠物内容与带货」分类及现有图标。当前该分类共 9 条。继续暂缓配图，没有新增图片或调用模型。

卖点图需要真实商品参考、1–3 个已确认卖点及确切文案；活动海报需要主题、文案及相关素材，用户要求出现的价格、日期和规则须提供；尺寸图需要数值、单位与部位对应关系，不从照片估算；步骤图需要确认过的 2–4 个步骤，不自行推断用法或用量；对比图需要分别标明 A/B 的参考及对比项和值，不将空缺当作零，不通过展示差异暗示未经提供的优劣。

这些预设交付单张图文设计稿，资料不足时提示词要求先补齐，文字与数字只用用户提供的内容，不自动扩展多尺寸、批量素材或发布任务。交付时要求核对排字、商品细节与对应数据；没有新增固定排版叠字工具，也不承诺文字逐字准确、工程图精度或可以直接发布。上述要求由 Agent 按提示词执行，未新增强制事实校验。

## 上下文与调用边界

- 指令由独立 `GET /api/imageCommands` 接口供网页使用，不注册到 Skill、`skillOperator`、MCP 资源或系统提示。未使用时，名称、描述和正文不会因本功能自动进入 Agent 上下文。
- 只有网页真人请求设置内部 `manualImageCommands` 标记。MCP `runAgent`、内部子 Agent 任务和 Agent 间消息不设置该标记，不展开预设。此标记不加入 MCP 或工具参数。
- 消息开头的 `/id` 必须大小写一致且后接空白或结束；ID 可由字母和数字组成并至少包含一个字母，支持 `/3dcartoon` 等原站命令。展开时保留后续补充的引号和换行。普通正文中的命令、代码块、纯数字、`/Users/...` 路径不展开。未知短命令由网页入口在建立模型流前返回 HTTP 400。`/skill:name` 沿用现有 Skill 路径。
- 首条消息在 SDK `message_start` 阶段展开；真人入队消息用消息对象的 WeakSet 标记，在消费或停止保存时展开，再拼接已有引导说明。展示元数据保留原始短命令，SDK 历史保存单条展开正文。队列模式转换保留标记。
- 未附带其他指令的目录或正文；已使用的单条正文会成为历史上下文，后续轮次仍可能携带。这里控制自动载入，不是额外的工具访问权限隔离。
- 预设不改变算力授权和工具权限；默认一张、不自动追加或重试。真实参考、用户要求和模型能力优先；只要文字的请求不要求实际生图。

## 实现与扩展

服务端 `lib/imageCommands.ts` 维护原目录、合并及展开，`imageCommandImports.ts` 保存完整通用迁入项，`petImageCommandImports.ts` 保存宠物领域补齐项。`imageCommandTypes.ts` 通过包 exports 向 Web 提供纯类型；`routes/imageCommands.ts` 提供网页接口，`routes/agent.ts` 标记真人请求，`agent/runtime/{index,delivery}.ts` 处理入队来源与实际投递。新增路由须运行 `bun run routes`。

Web `lib/imageCommands.ts` 共享加载状态，合并并发加载，失败可重开重试。`pages/home/{index,imageCommands}.vue` 提供入口和草稿衔接，`components/agent/skillMenu.vue` 与 `conversation/messageInput.vue` 复用菜单及富文本插入。首版内容为中文，不等同于 Skill 内容的双语支持。

预览图片放在 `apps/web/src/assets/imageCommands/<id>.webp`，由页面构建时引入，不加入指令接口或 Agent 上下文；新增同名图片即可接入卡片与详情。网页使用 640px WebP、卡片懒加载与异步解码，保留完整主体；没有图片的新增指令显示分类图标。原图、模型、提示词与处理方式见[预览图变更记录](changes/imageCommandPreviews20261114.md)。

修改数据后构建并重启 Server；修改页面后构建 Web，刷新或重启开发服务。没有持久化格式迁移；移除入口、接口及展开逻辑即可撤回，已保存历史中的正文保持原样。
