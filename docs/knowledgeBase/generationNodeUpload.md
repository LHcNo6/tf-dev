# 生成节点上传素材实施与维护

## 范围与实现方案

- 图片生成节点和视频生成节点在空白预览区域分别提供上传图片、上传视频的入口；已有输出时使用顶部替换入口。图片节点显示局部重绘标注图时仍可通过顶部替换入口上传。
- 复用各节点现有文件选择、上传、校验和输出逻辑，上传成功分别写入标准 IMAGE 和 VIDEO 输出。保留原输出文件以支持撤销与其他引用；上传失败不覆盖原输出。
- 图片生成节点的 IMAGE 输出可连接视频生成节点的输入，作为视频模型支持的参考图片或首尾帧；不自动开始生成。视频上传替换输出不自动提取尾帧，仍可手动提取。
- 不增加接口、配置、服务或迁移，不改变模型支持的素材类型和限制。现有上传限制为非空、对应媒体类型且不超过 100 MB。

## 实施和验收

1. 在两个生成节点的空预览区域增加上传按钮，沿用现有操作状态限制和错误提示。
2. 验证图片上传后连线，以及先连线后上传、替换图片后视频节点引用更新；检查画布保存重开后引用保持。
3. 验证视频上传、替换、播放，上传失败和生成中禁用，确认手动提取尾帧行为不变。
4. 分别执行两个节点类型检查与开发构建，检查产物同步；安全重启相关服务并验证网页和插件可访问。更新节点说明和本文件的实际验证结果。
5. 对照以上范围审查代码及文档，检查失败时原输出、历史文件、撤销与连线；记录未验证边界。

## 验证记录

- 两个生成节点的 `typecheck` 和 `NODE_ENV=dev` 构建通过，`build/nodes` 与 `data/nodes` 对应文件 SHA-256 一致。
- 按本方案审查时发现顶部工具栏仅在选中时挂载，已将文件输入框移到始终挂载的预览区域，避免未选中节点时上传按钮找不到输入框；修复后重新通过类型检查和开发构建。
- 使用节点脚手架的实际引用读取与 Vue 响应式监听，在先连线的情况下验证空输出、首次写入 IMAGE 和替换 IMAGE 时，下游依次读取到对应路径；未通过网页实际操作验证。
- 开发网页 `http://localhost:5173/` 可打开，服务端两个节点文件接口均返回包含新上传入口的产物。现有服务的媒体任务保存在进程内，无法列举所有运行任务，故保留现场未重启，避免中断任务。
- 尚未在画布中实际验证文件上传、播放、图片连接、保存重开、错误分支、生成中禁用、尾帧提取及真实供应商生成；供应商对参考素材的最终支持取决于模型和模式。
