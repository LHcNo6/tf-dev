# 合成视频节点维护

## 功能与实现

`packages/nodes/videoComposeNode` 提供视频合成画布插件，输入可混合上游 VIDEO 引用与上传素材；片段顺序、裁剪范围、音频及字幕设置随画布保存。结果为工作区内 MP4 视频引用，可连接下游节点。

选中节点时显示共享媒体工具栏，通过 `nodeSkeleton` 的下载逻辑保存当前结果，并通过播放器进入全屏；没有可读取的结果时下载按钮禁用。

桌面端使用原生另存为窗口；支持 File System Access API 的网页浏览器先选择保存位置，再读取并写入视频。其他浏览器使用浏览器自身的下载设置决定保存位置。

`composeVideo.ts` 通过节点 FFmpeg 桥接读取流与时长，裁剪各片段，将画面统一为首段偶数尺寸、30 fps、等比补黑边，并将音频统一为 48 kHz 双声道；无声片段补静音。拼接后按设置混音或替换背景音，字幕可烧录或转为 mov_text 轨道。合成前检查 libx264、AAC 及所需的字幕滤镜；失败或取消不覆盖上次结果。

素材存入 `assets/<节点 ID>/`，新输出使用唯一文件名；取消和失败清理本次未完成文件，已成功的旧文件保留以支持引用和撤销。字幕路径只接受安全字符，字幕内容须为 UTF-8 SRT 或 ASS。

## 长视频工作流与节点工具

长视频开始时可选交互模式或自动模式。自动模式一次确认目标、模型候选、规格、生成调用总上限及每对象失败重试上限；按范围自主规划与串行执行，实际尾帧、顺序和合成核验仍不可省略。调用与重试边界由 Agent 指令和台账约束，非节点层强制预算；等待超时、状态不明或需要人工裁剪时保留成果并停止。

内置 `longVideoWorkflow` 面向超过 30 秒的通用分段制作，先形成全片分段表，以节点实际模型能力和用户授权串行生成各段；第二段起以本次前段视频的有效尾帧作为首帧，再核对来源与顺序后合成。Seedance 提示词由已安装 `workflow` 的 PART A 管理，首尾帧例外仅适用于该长视频工作流。严格时长方案需要裁剪时，由用户在合成节点设置裁剪范围，Agent 读回核对后执行。

合成节点提供 `node:getComposeState`、`node:setClipOrder`、`node:startCompose`、`node:waitCompose` 和 `node:cancelCompose`。顺序设置要求全部连接来源唯一、均有输出且无上传片段；启动要求完整传入来源、路径和裁剪快照。状态包含本次尝试 ID、输入快照和当前输入是否匹配；结束状态只属于当前打开节点后的尝试，旧输出不代表本次成功。合成期间输入变化会阻止提交新结果。等待最多 30 秒，取消等待不取消合成；取消合成不删除旧结果。手动上传及合成界面继续可用。

普通画布保存不会取消或等待合成，合成成功后输出由画布自动保存。素材上传期间仍阻止显式保存，合成期间阻止节点刷新；删除节点、切换工作区或画布以及卸载节点仍会取消任务。Agent 节点工具调用后的保存也遵循此规则。

## Agent 启动后立即取消的排查记录

2026-11-10，`source-qa` 的画布 3 中，两段视频已生成并确认采用，但 Agent 两次启动合成后均在进度 0 收到 `cancelled`，未产生新成片。隔离画布用一个已连接视频复现了相同结果，排除了必须使用原两段素材才能触发这一现象。

原因是两个生命周期约定发生冲突：画布将 `nodeTools` 作为非只读操作，调用完成后通过 `flushSave` 向节点发送普通 `save` 事件；合成节点原先在该事件中调用 `cancelAndWait`，立即中止刚启动的后台任务。`startCompose` 返回的 `running` 是保存之前取得的状态快照，不能作为任务最终成功的证据。

修复只调整合成节点的普通保存处理：不再取消或等待任务，让任务继续执行；删除仍走取消并等待，节点刷新仍在合成中拒绝。完成后继续用输入快照防止变化后的素材被误提交，并通过画布自动保存输出。排查类似情况时，应记录本次 `attemptId`、等待终态并核对输出，区分普通保存、节点刷新、删除和画布卸载；已有旧输出不能证明本次成功。

已初始化的数据目录首次启动时补入未安装的内置长视频工作流，不覆盖同名目录；开发源码修改不会自动覆盖已安装副本。运行时需实际发现 `workflow` 及其参考资料，缺失时工作流会停止受影响阶段。

长视频的状态与交付资料属于 `workflow`，读取时 `skillOperator` 的 `name` 应为实际发现的 `workflow`、`path` 为 `references/stateAndDelivery.md`，而非将该路径放在 `longVideoWorkflow` 下。Seedance 任务另读同一技能的画布执行资料；读取失败先核对技能名、作用域和路径。

安装复制发生普通异常时会清理本次创建的目录；若进程在创建目录后被强制终止，可能留下不完整目录，需检查并移除该不完整目录后再启动。
