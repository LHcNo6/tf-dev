# Agent 回复与工具活动

[返回项目知识库](readme.md)

## 当前行为

工作区 Agent 对话按原始顺序展示正文、思考和工具活动。同一条回复中连续的普通工具调用合并成一个默认收起的摘要，显示调用数量、当前执行的工具，以及失败和中断次数；正文、思考和交互表单分隔活动组。空白内容不单独占位。

展开活动组后，仍可查看每次调用的状态、参数和结果，并使用原有工具界面的节点定位入口。收起时不挂载组内工具界面，避免大量节点 ID 标签和工具组件挤占回复。组展开状态仅属于当前组件，虚拟列表卸载或刷新后重新默认收起。

`askUser` 及带 `question` 的工具仍直接展示，保证交互表单不被外层活动组隐藏。浏览器工具继续使用已有的独立画面归组规则。展开的工具行显示真实名称；`nodeTools` 额外显示实际 `node:函数名`，不再全部标为“操作工具”。

这只是展示投影，不改变原始 `parts`、工具调用顺序、执行协议或会话保存格式。独立 `singleAgentDialog` 暂未接入活动归组，其工具名称随共享组件更新。

## 文字与视觉层级

工作区消息正文和用户消息使用 14px 基准字号、1.75 倍行高，并跟随应用现有的全局缩放。工具活动使用独立的填充背景、边框、工具图标和 13px 半粗标题；执行状态使用较次一级的常规文字，失败和中断计数有单独标签。运行中额外强调摘要边框。

展开的工具名称使用 13px 等宽字体和主文字色，状态以独立标签显示；工具参数、结果标签和正文使用更清晰的颜色与行距。长工具名收缩省略，悬停可查看完整名称。隐藏工具标题内第三方组件的空白占位，避免占位与工具名竞争宽度。样式通过主题变量适配浅色和深色，不改变全局配色或其他页面字体。

## 实现入口

- `apps/web/src/components/agent/conversation/messageList.vue`：生成展示分组，保留交互表单与浏览器画面路径。
- `apps/web/src/components/agent/toolActivity.vue`：原生 details/summary、状态摘要和按需挂载；支持键盘操作、主题变量和减少动态效果偏好。
- `apps/web/src/components/agent/toolMessage.vue`：原始工具界面、参数和结果，以及具体工具名称。
