# 宠物短视频工作流维护说明

## 使用与行为

在项目中打开画布，向 Agent 描述 30 秒以内的宠物带货视频，或明确指定“宠物短视频工作流”。Seedance 2.5 使用 `petCommercePromptSd25` 完成创作与定稿；其他模型先使用 `petCommercePrompt` 创作，再用 `videoPromptAdapter` 按模型版本与输入方式整理最终提示词。技能生成脚本、资产提示词与一条完整视频提示词，工作流创建文本、宠物主角、商品、场景和视频生成节点。商品节点始终创建，但只有启用且素材就绪时才作为视频参考；用户可在图片生成节点上传素材。生成前按所选模式核对授权，随后依次准备缺失图片并生成视频。

视频默认使用 480p，用户明确指定其他分辨率时按其要求；视频生成时长与最终剧本总时长一致。工作流使用实际节点端口、输出、参考顺序及模型能力；模型不支持所需参考数量、剧本时长和所选分辨率时保留画布并说明，不静默修改。失败重试按下方执行模式处理，取消或状态不明时不自动重试。任务依赖打开的画布和节点，不保证关闭、切换后后台续跑。模型、素材或提示词在授权后发生变化时，受影响调用须重新核对授权。

## 宠物带货创作规则

`petCommercePrompt` 默认将带货设计为宠物模仿人类主播的中文画内口播，保持宠物身份与物种形态；自然动物表演、旁白或无声按用户指定处理。每镜写姿态与视线、前爪与商品接触、动作过程和终态、景别/机位/光线、逐字台词及停顿，按口播时间安排镜头，不强制每镜运镜或环境动态。商品卖点与外观依据用户和真实资料，不把生成的未知包装结构或商品效果当作事实。

创作技能仅交付成果，不调用生成。只要求脚本、分镜或提示词时，明确目标为 Seedance 2.5 则宿主直接路由到 `petCommercePromptSd25`，否则路由到 `petCommercePrompt`；完整画布制作由 `petShortVideo` 按实际选中模型读取。跨技能先查目录及 scope，附属资料以所选技能的 name 和 `path=references/shotGuide.md` 读取。模型尚未确定时可以先写通用草稿，实际模型确定后、媒体生成前须使用对应技能完成最终方案；模型变更影响提示词时核对原授权。无商品分支只省略商品内容，保留宠物表演方法。

Seedance 2.5 版依据官方指南按参考职责和连续事件阶段写作，描述宠物姿态、视线、前爪与商品接触、动作终态、镜头和逐字口播；需要控制时间时使用整数秒区间，保留用户明确要求的小数时间但不承诺精确执行。画内口播、画外旁白、音色参考和已有台词音频分别处理。视频节点的 `{{ref N}}` 按真实连接和 `referenceOrder` 映射；待生成素材在授权方案中标明节点及绑定规则，素材就绪后再核实实际引用。素材、口型和商品文字仍需实际检视。

声音不再固定为“只生成对应音效”。口播明确说话者、台词、时间、声音人设和画内/画外方式；工作流核对实际声音开关和参考输入等执行条件。中文口播、口型与逐镜控制等表现效果缺少资料或联网失败时，在已授权范围内保留目标并尝试生成，说明效果未经验证；接口或可靠声明明确不支持必要执行条件时暂停，不静默改成旁白或无声。生成结果仍需实际观看、听音验收。

## 多模型与长视频规划

`videoPromptAdapter` 以确切版本和输入方式路由：优先使用本地已核实的官方来源规则，例如可灵 VIDEO 3.0 和 Veo 3.1；官方规则缺失或不适用于本次模式时，读取第三方 `videoPrompting` 中匹配版本及模式的专篇；两者均无匹配时使用通用方案并标记专门优化未核实。第三方专篇包括 MiniMax H3、Wan 2.2、Ovi、LTX 等，具体索引以适配器为准。当前未找到可核实的 Wan 3.0 官方提示指南，上游也没有 Wan 3.0 专篇，因此仍使用通用方案，不能套用 Wan 2.2 规则。官网或第三方 Skill 对功能的描述不能替代实际节点能力。

`videoPrompting` 来自 Square-Zero-Labs 的 Apache 2.0 项目，包含完整模型参考及示例；为 Toonflow 将技能名、目录及引用路径改为小驼峰，保留来源提交、修改说明和完整许可证。适配器以全局 scope 读取来源和匹配专篇，第三方只负责适配提示词格式，不覆盖用户台词、商品事实、真实引用、授权与 Seedance 既有定稿规则。修改源码后需要同步安装副本，同名现有 Skill 不在启动时覆盖。

`longVideoWorkflow` 宠物带货分支读取适配器中的宠物规划参考，记录主播表演、商品事实、逐字口播和跨段连续性。非宠物长视频不强制使用该参考；Seedance 长视频最终提示词仍由 `workflow` PART A 定稿。现有尾帧绑定不能同时携带其他参考，冲突时保留素材并交由用户选择受支持方案。

## 执行模式

制作开始时选择交互模式或自动模式。交互模式继续在生成前审阅并授权具体方案；自动模式先确认本次目标、模型候选、规格、总调用次数及每个对象的失败重试上限，之后在范围内自行规划和执行。只有明确失败才可在余量内重试，未知状态与等待超时不重复生成；结果未审片或未采用时如实标记。授权与次数由 Agent 按提示词和台账核对，节点工具不提供独立的强制预算。

## 实现与安装

- `packages/skills/petShortVideo/` 包含画布执行工作流；`packages/skills/petCommercePrompt/` 和 `packages/skills/petCommercePromptSd25/` 分别包含通用和 Seedance 2.5 专用创作规则及逐镜示例。专版根据官方建议独立编写，运行时不调用或更新外部 `sd25-pe`。宠物工作流从 1.1.0 起移除附带的 Lengyi 快照和模板，独立安装的其他通用 Skill 不属于本次删除范围。
- 图片和视频生成节点复用 `useNodeGeneration` 的 `node:waitGeneration`；画布工具内部汇总每次最多30秒的等待，图片第5分钟检查本次调用记录一次、总上限7.5分钟，视频第10分钟检查、总上限15分钟。到上限只结束等待，详见[生成等待维护](generationWaiting.md)。调用取消或节点卸载释放等待，旧输出和 `idle` 不能证明本次成功。
- 已初始化的数据目录缺少 `petShortVideo`、`longVideoWorkflow`、`petCommercePrompt`、`petCommercePromptSd25` 或 `videoPromptAdapter` 时，服务启动时补装；存在同名目录时保留现有内容。已有宠物工作流更新时需同时安装两个创作 Skill 并更新工作流主文件；后续源码修改不覆盖已安装的同名 Skill。正常插件更新按整包替换规则处理，用户旧版本中的其他资料需自行确认和保留。
- 提示词和素材经画布节点工具写入；节点工具在画布挂载期间可用。等待前后需要核对生成状态和参考，不将当前节点状态作为可跨会话恢复的任务记录。
