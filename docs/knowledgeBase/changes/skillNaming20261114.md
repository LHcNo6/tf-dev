# 2026-11-14 Skill 应用导向名称与触发描述

## 实际变更

调整 9 个内置 Skill 和 3 个已整理的第三方 Skill，共 24 份中英文入口的展示名、描述和主标题。名称以用户任务命名，例如“创意与剧本转视频”“宠物带货脚本与提示词”“长视频分段制作与合成”“小说改编与分集视频制作”；完整对照见 [Skill 名称、描述与语言选择](../skillLanguages.md#应用导向名称与描述)。

描述先写使用场景，再写输入和交付物，并说明与相邻技能有关的模型、时长和执行边界。区分只交付脚本/提示词、已有方案的模型适配、实际短视频制作、长视频分段合成和分集制作。Agent 自动发现与 `skillOperator` 列表读取技术 `name` 和 `description`，因此这些选择依据直接写进描述，不依赖展示名或加载正文后才知道用途。

技术 `name`、目录、资料路径和 `/skill:name` 调用标识保留；既有技能引用继续有效。正文只调整主标题，原有创作方法、工具调用、模型路由和授权规则保留。9 个内置技能的中英文 `metadata.version` 同步递增补丁版本；第三方上游版本及 `sd25-pe` 的 `skill_version` 保留，不把本地文案修改声明成上游升级。

## 关键位置

- `packages/skills/*/SKILL.md`、`en.md`：9 个内置双语入口。
- `packages/skillLocales/*/zh.md`、`en.md`：3 个第三方双语入口；部署映射见 [译本说明](../../../packages/skillLocales/readme.md)。
- `docs/pluginDevelopment.md`：补充面向任务的命名方式，以及触发条件必须进入描述的要求。
- `docs/knowledgeBase/skillLanguages.md` 和知识库、变更索引：维护当前名称与选择依据。

## 打包、同步与回滚

修改前核对 24 份已安装入口均与源码一致，备份到 Git 忽略的 `data/skillBackups/skillNaming20261114/`。同步前再次核对旧入口未发生变化，然后将新入口复制到对应 `data/skills/<技术 name>/`，第三方中文 `zh.md` 映射为目标 `SKILL.md`，保留其余参考资料、许可证和原文件。

Skill 为 Markdown，无编译步骤。本次已打包同步受影响入口至 `build/skills/`、`build/skillLocales/`，并更新译本说明；没有修改 Web/Server 可执行源码，因此未重新构建无关的 Web、Server、MCP 或桌面产物。其他部署仍遵守首次补入、保留用户修改的安装策略，需要核对和更新已安装 Skill，不能仅更新源码或启动服务就认为已覆盖数据目录。

回滚可从上述备份恢复本机 `data/skills/` 入口，并按内置与第三方的原映射恢复源码、版本和构建包入口；不改画布或生成媒体。恢复两种语言时须成对处理。
