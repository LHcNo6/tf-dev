## 行为与实现

- `apps/server/src/lib/imageCommands.ts`：在现有目录末尾加入 8 条 tuple 数据，复用接口、来源映射、范围判定及单条展开。本轮没有修改 Web 源码、路由、类型、配置或依赖。
- 通用摄影指令要求主体参考。黑底保留暗部层次，不改浅毛色来分离主体；轮廓光兼顾正面可读性，不自动切换黑底。素描用灰阶排线塑形，保持斑纹位置，与纯线稿分开。
- 等距场景要求场景描述或参考；准确复现时先补布局，未知区域仅为设计推演，不作为工程图或测量结果。默认仅画指定环境与物件。
- 黏土与刺绣以脸型、耳形、主色和标志斑纹保持宠物身份，允许简化细毛。黏土交付单张静态角色图；刺绣交付布面针脚肖像预览，不是立体羊毛毡，也不是机器针迹文件。
- 纹样只重复同一宠物的简化图案，额外元素须用户指定；不承诺边缘无缝拼接、矢量输出或印花生产精度。
- 周边先区分宠物图案与载体，缺载体先询问，准确复现真实商品须补载体参考；宠物以图案应用于表面，只做一种载体的一张效果图，不将活体放进容器。已有成稿不擅自重设计；不编造规格、价格或在售状态，不承诺制造可行性或生产文件。
- 全部默认画幅 `1:1`，用户明确要求及模型实际能力优先。资料不足先补齐、身份保持和排字要求由 Agent 按提示词执行，没有新增强制校验接口。
