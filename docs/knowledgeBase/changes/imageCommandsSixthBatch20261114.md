## 行为与实现

- `apps/server/src/lib/imageCommands.ts`：仅追加 4 条目录数据，沿用来源映射、集合判定、接口和手动单条展开。没有新增 Skill、工具、路由、类型、配置或依赖。
- `apps/web/src/pages/home/imageCommands.vue`：为「包装与品牌」映射现有 Tabler 库的 `IconPackage`；复用现有分类、搜索、详情和草稿交互，没有新增布局或样式。
- 包装设计需要一种包装形式、设计方向及确切文案或明确无字要求，交付单主视角的一张新方案。标签设计需要形状或比例和确切内容，交付平面方案，标签本体不因方形画布而强制方形。两者不编造商品事实、认证、条码或二维码，不承诺排字准确、刀模、印刷文件、精确尺寸或制造可行性。
- 开箱先区分宠物、真实包装和实际内含物参考，确认数量、开合程度和指定瞬间，不从封闭包装推断内部结构或赠品，不增加人类手臂，不扩展步骤或视频。
- IP 视觉板需要宠物参考和气质方向，在单张图内整理主形象、配色色块和已有元素提炼的辅助图案。已有素材按提供内容保留，未提供标识时不创建商标，未提供准确色值时不标精确色号；新配色明确属于设计提案，不扩展品牌手册、字体、矢量标志或授权证明。
- 上述参考职责、缺资料先补齐、身份保持和排字等约束由 Agent 按提示词执行，没有新增强制事实校验或生产排版工具。
