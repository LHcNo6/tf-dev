# Agent 工具活动收起展示

日期：2026-11-13

## 问题与实际行为

此前工作区 Agent 的每次调用都单独占一行，画布工具还会额外渲染节点 ID 标签，导致较长任务的执行记录淹没正文。现在同一条回复内连续的普通工具调用合成默认收起的“工具活动”摘要，显示数量、当前工具、失败与中断次数。正文仍按原顺序显示，展开后保留原始调用、参数、结果和节点定位入口。

`askUser` 与带 `question` 的工具直接展示；浏览器画面继续使用原有规则。工具详情改为真实工具名，节点函数附带实际函数名。未修改执行链路、历史存储与调用数据，也未将活动分组接入独立 Agent 弹窗。

## 实现与设计

入口和维护说明见 [Agent 回复与工具活动](../agentReplies.md)。使用已有主题变量和轻量的折叠行，将正文作为阅读重点；活动详情按需挂载，减少默认 DOM 和工具插件加载。只为正在调用的状态使用旋转图标，并遵守减少动态效果偏好。本次属于局部修改，由主 Agent 自查，未安排独立视觉评审。

新增摘要文案已补齐二十个非简体中文语言文件，中文及来源索引已执行仓库提取入口。提取同时反映当前源码的已有文案变化；来源索引沿用原有键顺序，减少与文件系统遍历顺序有关的重排。
