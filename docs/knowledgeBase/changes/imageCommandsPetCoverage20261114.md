## 实现与领域边界

- 新数据模块按分类维护名称、参考要求、画幅、独立效果段与来源，统一生成目录所需字段；`imageCommands.ts` 并入已有接口和手动展开，不新增 Skill、工具、路由、参数、依赖或联网同步。
- Web 复用原卡片、详情、搜索和草稿交互，仅增加 6 个宠物分类图标映射。完整目录共 22 类，沿用通用迁入时增加的分类栏滚动。
- 肖像、艺术和数字角色保持宠物身份及动物结构；材质方向区分宠物形状的非活体摆件与真实宠物，不表现冰封、充气、金属化的活体过程，不把巧克力或糖果造型当作宠物食品。
- 结构分解、蓝图只用于有资料的宠物用品，不从封闭外观推断内部。X 光、热成像是虚构风格和伪彩色，不生成检查结论、病灶或体温。照片编辑保留身份，未知区域属于推演，不承诺像素锁定。
- 户外投放、社交帖子、通知、搜索广告只作设计预览，不伪造实际发布、合作、排名或互动量，不执行投放、发布、发通知或抽奖。评价、价格、数量、规格、活动规则仅用提供事实，资料不足先补齐。
- 生活场景保持合理尺度和接触，厨房、泳池、车内、阳台等说明指定位置与表现方式；宠物人群拖影要求先确认是否允许背景人物。用品、货架、包装与载体图不默认增加活体宠物。
- 全部沿用现有算力权限与真人手动触发边界，默认单张，不自动追加或重试。提示词约束没有转化为强制事实校验、结构表单、医学检测或生产排版能力。
