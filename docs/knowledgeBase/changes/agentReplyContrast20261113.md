# Agent 回复对比度与字体层级

日期：2026-11-13

## 实际修改

此前工具活动、状态与正文使用相近的小字号、低对比度灰色，工具摘要没有独立背景，较难分辨内容类型。本次沿用已有折叠逻辑，调整以下视觉层级：

- 工作区正文和用户消息由 13px、1.6 倍行高改为 14px、1.75 倍行高，跟随既有应用缩放；消息间距略微增加。
- 工具活动增加填充背景、边框、16px 工具图标和半粗标题。正在运行时强调边框，失败与中断计数使用独立标签。
- 工具名使用等宽字体和主文字色，状态使用独立标签，参数与结果的标签加深、加粗，数据字体和行距增大。
- 工具名保持与状态同一行，长名称省略并提供完整名称悬停提示；移除第三方工具标题的空白占位，避免它占用工具名宽度。
- 思考标题与详情改用常规文字色，提高可读性。

实现位于 `apps/web/src/components/agent/toolActivity.vue`、`toolMessage.vue` 和 `conversation/messageList.vue`。维护说明见 [Agent 回复与工具活动](../agentReplies.md)。仅调整现有组件，无新增依赖、文案键或动效；工具执行和历史保存格式不变。

- 读取实际样式：浅色标题 `#303133`、状态 `#606266`，摘要背景 `#f5f7fa`，对比度分别为 12.13:1、5.69:1；深色标题 `#f1f3f7`、状态 `#d1d6df`，背景 `#282c34`，分别为 12.60:1、9.60:1。此计算仅覆盖摘要这两种文字，不代表全部界面可访问性验收。
