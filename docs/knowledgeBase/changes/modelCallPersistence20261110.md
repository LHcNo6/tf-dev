# 图片和视频调用记录持久化（2026-11-10）

画布 3 的双宠喜剧 G01 有视频文件，节点数据无模型调用记录。历史素材窗口扫描节点素材目录；它能看到视频不证明模型调用记录存在。当时调用结束才写画布，实际丢失环节未证实；本次不补录旧记录。

新图片、视频调用在服务端写入独立记录后才调用供应商；运行和终态使用同一调用编号，成功记录包含结果路径。存储和更新在 `apps/server/src/utils/media/calls.ts`、`tasks.ts`，窗口在 `packages/nodeScaffold/src/nodeSkeleton.vue` 合并旧记录。独立记录保留全部未结束及最近 100 条已结束记录；终态写入失败时进程内保留结果并可在窗口重试。服务重启后尚未结束或未成功保存终态的记录显示状态未知，不能证明远端结果；不自动重试生成。

节点保存首次调用时的画布标识，画布重命名后仍用该标识关联；完整复制画布时若节点 ID 与标识均被复制，副本会引用同一批记录。节点删除后记录文件保留。工作区被删除、磁盘损坏或持续不可写时无法保证可读取；终态仅在服务进程存活时可重试保存。记录不保存提示词或密钥，但错误详情可能包含上游返回的敏感内容。

验证：服务端、节点脚手架、图片节点和视频生成节点类型检查通过；全部节点、Web、Server 构建通过，图片及视频生成节点构建副本与安装副本哈希一致。使用不存在的供应商发起不消耗算力的本地请求，提交响应确认记录已保存，同一编号随后显示失败、结束时间及失败阶段；工作区目录不可写时接口明确返回未提交。浏览器打开画布 3 的 G02 调用记录窗口，旧成功记录可见。前后端重启后页面和节点文件接口可访问。

真实供应商成功、取消、长时间断线、服务重启后记录读取、终态磁盘写入失败、并发、重命名及独立记录窗口交互尚未验证；不将构建通过等同于功能验收。详见[模型调用记录](../nodeModelCalls.md)。
