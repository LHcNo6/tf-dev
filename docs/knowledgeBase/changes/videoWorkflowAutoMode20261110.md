# 视频工作流自动模式

日期：2026-11-10。

宠物短视频与通用长视频在任务开始选择交互或自动模式。交互模式保留具体方案确认；自动模式须先明确目标、规格、图片与视频模型或有序候选、总生成调用次数和每对象失败重试上限，并取得本次范围授权。随后在范围内生成创作方案、配置画布并执行；仅明确失败可在余量内重试，重试须为剩余对象保留首次调用额度。任务仍依赖打开的画布，状态不明、超时、能力不兼容或需要人工裁剪时保留成果并报告。自动使用本次成功结果不等于人工审片或采用。

宿主规则位于 `apps/server/src/agent/runtime/prompt.ts`，两个技能位于 `packages/skills/petShortVideo/` 与 `packages/skills/longVideoWorkflow/`；长视频引用的 `workflow` 与执行、交付参考文件限定自动模式例外。主题说明见[宠物短视频](../petShortVideo.md)与[视频合成](../videoComposition.md)。已安装技能需要同步更新，源码不会自动覆盖同名安装副本。

验证：服务端类型检查与构建通过；源码、构建与已安装技能主文件同步，技能接口读取到三个更新后的版本；网页及服务端此前返回 HTTP 200。未进行实际画布端到端、模型付费调用、失败重试或 Seedance 首尾帧合成验证。调用和重试上限由 Agent 遵循指令和台账，不是程序级强制拦截，不能保证模型始终遵循；后续需要真实运行验收。无数据迁移；回退时需同时恢复宿主提示词、三个技能及安装副本。
