# 无限画布品牌与外观调整

日期：2026-11-13

根据确认的首页设计，将用户界面的产品名称和品牌图标调整为“无限画布”，移除首页左下角 GitHub 按钮；将首页背景中的旧图案替换为新图标的无限符号轮廓。首页布局和点阵动画保留，新增蓝灰色浅色外观、圆润卡片和悬停、按下、键盘焦点反馈。

新默认外观为浅色、雾蓝和 12px 圆角；已有显式外观配置不覆盖。品牌图标同步到 Web、加载页、Agent、macOS 图标集、Windows ICO 和原生启动动画；相关展示文案及翻译字典同步调整。为兼容现有工作区与更新，内部包名、协议、文件标记、安装身份、上游仓库及更新源仍保留原标识。

首页点阵 SVG 原图按源区域裁剪在 Chromium 中可能为空，改为先渲染到离屏画布再裁剪；背景图案使用透明轮廓，避免把图标底板当成点阵形状。实现位置和维护注意事项见[外观与品牌](../appearanceAndBrand.md)。

## 验证

- Web、服务端、桌面和 Android TypeScript 检查通过；Web 和服务端构建通过。检查任务状态后重启了本地前后端，开发页面、API 代理及构建版静态资源可访问。
- 曾误运行桌面构建；较早一次通过，最后一次在安装镜像卸载时提示资源忙而失败。临时卷在确认无进程占用后正常卸载，没有安装或覆盖本机应用；最终桌面安装产物未完成验证。
- 本地 Chromium 检查了浅色首页的新名称、图标、点阵轮廓、默认配色及 GitHub 按钮移除；界面设置中显示雾蓝和 12px 默认圆角，另用临时数据目录查看了深色首页。
- 使用 macOS ARM ThorVG 运行时渲染并查看原生启动动画的加载与完成阶段；从构建出的 macOS 应用图标中提取并查看新图标。
- Android 构建脚本在 macOS 上提示仅支持 Windows SDK，故本机未生成 APK。

未验证 Windows、Intel Mac 或 Android 的实际安装、更新和原生启动；未覆盖所有语言及全部页面的人工视觉验收。已有外观自定义设置会继续覆盖默认值；旧安装中的原有快捷方式不会主动删除。
