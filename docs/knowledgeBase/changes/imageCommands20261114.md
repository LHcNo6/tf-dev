# 2026-11-14：手动图片指令库与宠物预设

[返回变更索引](readme.md) · [主题维护说明](../imageCommands.md)

## 实际变化与关键实现

首页左栏增加「指令库」，提供 24 条效果、搜索、通用/宠物筛选、6 分类和详情。支持复制和填入草稿；不自动发送，保留原正文、附件并显示参考要求。预览图按需求暂缓，本轮交付文字卡片。

首页与项目聊天共用 `/` 菜单，保留现有 Skill。修正首页卡片裁切菜单及弹层方向、单独 `/` 选择后的多余字符、插入时误删绝对路径，以及短视口详情弹窗底部操作不可见的问题。

服务端新增 `lib/imageCommands.ts`、纯类型及 `GET /api/imageCommands`；网页入口、共享加载器和菜单引用同一数据源。数据不进入 Skill、系统提示或 MCP 资源。`routes/agent.ts` 独立标记真人请求，`agent/runtime/{index,delivery}.ts` 标记入队对象并在实际投递时展开一条，原文作为聊天元数据保留。MCP 和内部 Agent 默认不能展开。路由由 `bun run routes` 自动生成，未新增依赖或测试模块。

- 实际操作搜索/筛选/空结果恢复、详情和复制反馈、填入草稿、正文保留、首页 `/` 键盘选择、单独 `/` 替换、绝对路径保留。项目聊天实际插入 `/petPlush `，菜单同时含 24 条图片指令与 12 条 Skill。
