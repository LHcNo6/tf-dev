# 画布菜单与工具图标替换

日期：2026-11-13

添加节点菜单的十种内置节点及上传入口改用统一的线性矢量图标，分别对应文本、图片、视频、音频、生成、三维、逐帧分析和合成等语义。底部工具栏的素材库、整理、地图、网格吸附、连线和适应视图也换用同系列图标，保留开关状态提示。

菜单映射位于 `apps/web/src/pages/workspace/panels/canvas/components/nodeMenuItems.vue`，未命中映射的节点使用插件提供的图标；工具栏位于 `canvasControls.vue`。维护入口见[外观与品牌](../appearanceAndBrand.md)。

验证：Web 构建与类型检查通过；浏览器检查节点菜单各项图标及工具栏，重启开发服务后确认菜单图标加载。开发页面和构建预览返回 HTTP 200。构建有大体积分包提示。
