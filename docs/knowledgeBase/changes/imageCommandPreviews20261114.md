## 需求与设计

用户要求通过配置的安泰信 MCP 生图，让已有指令卡片展示效果，优先尝试 Flare。沿用首页蓝灰主题、分类和手动使用流程，以图片作为卡片主角，点击后查看完整预览与提示词。

素材使用原创虚构金棕白色柯基，用品统一为鼠尾草绿陶瓷碗和奶油色配件。预览用于说明效果，不代表真实商品或身份保持能力的保证。没有使用 Xavvi 的图片、私人宠物素材、已有业务文件或聊天内容作为外部生图输入；图生图仅引用本次原创白底图。

## 实现

- `apps/web/src/assets/imageCommands/<id>.webp` 与指令 ID 一一对应，由页面的 Vite glob 引入；预览元数据不加入服务端目录、Skill 或 Agent 上下文。
- `pages/home/imageCommands.vue` 增加方形图片、分类角标和详情预览；保留筛选、搜索、复制和填入草稿，沿用现有悬浮动效，不新增自动发送。
- 图片以 `object-fit: contain` 展示，保留完整主体，卡片使用懒加载与异步解码。未提供图片的未来指令仍可使用分类图标。
- 原始 PNG 保留在 `outputs/imageCommandsFlare/`；网页使用 640px WebP（quality 85）。头像预览由本次原创白底图裁切生成，不算另一张模型生成图。
- 生图提示词及来源见同目录的 `imageCommandPreviewSources20261114.json`。工具未提供实际费用，不估算失败或成功请求的成本。

## 最终素材

全部 24 个指令均已配图：20 张 Flare 成功产物、3 张 Sunburst 成功产物（水彩、油画、短视频封面），以及 1 张从原创白底图裁切的头像。共保留 23 张原始 PNG；网页 24 张 WebP 共 795,482 字节，单张约 17–89KB。

Flare 的部分图生图请求返回 HTTP 524，后续采用文生图；部分文生图也有 HTTP 524 或连接中断，使用简化提示词或切换用户已授权的 Sunburst 补齐。没有拿失败响应当作成功图片，也未将远程临时 URL 留给运行时加载。工具未提供实际费用或失败计费情况。

- 已核对并重启本任务的 5173 Vite 进程。3000 服务继续读取更新后的 Web 静态产物，无服务端改动，不重启业务进程。
