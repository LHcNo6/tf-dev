# Seedance 2.5 宠物带货提示词与工作流接入

日期：2026-11-11。

新增 `petCommercePromptSd25` 1.0.0，显示名为“宠物带货提示词（Seedance 2.5 版）”。它依据火山方舟官方指南及现有宠物带货规则，编写拟人主播、商品事实、参考素材职责、逐镜动作与逐字口播；按阶段和终态组织，必要时使用连续的整数秒时间区间，不把时间、口型或商品文字写成质量保证。声音分为画内台词、画外旁白、音色参考及参考音频承载台词，参考编号以实际节点连接映射。逐镜示例与规则在技能目录中自包含，不在运行时调用或更新外部 `sd25-pe`。

`petShortVideo` 升至 1.2.0：目标模型为 Seedance 2.5 时读取专版，其余模型读取原通用版。目标模型未确定时的通用草稿须在最终模型确定后、生成前按对应技能定稿；模型变化时依据交互或自动模式核对授权。宿主为明确的 Seedance 2.5 宠物创作请求路由专版；已初始化数据目录缺少新 Skill 时在服务启动补装，同名目录仍保留。原通用 Skill 保留，生成次数、授权和现有 480p 默认不变。

主要位置：`packages/skills/petCommercePromptSd25/`、`packages/skills/petShortVideo/SKILL.md`、`apps/server/src/app.ts`、`apps/server/src/agent/runtime/prompt.ts`。维护入口见[宠物短视频](../petShortVideo.md)，官方资料与比对证据见[专项调研](../../research/seedance25PromptResearch20261111.md)。

## 验证与边界

服务端类型检查和构建通过；服务启动后，新 Skill 在已有数据目录自动补装，宠物工作流旧主文件备份后同步为 1.2.0。新 Skill 与工作流的源码、构建和安装副本一致；实际 `skillOperator` 能列出并读取工作流、通用版、专版及专版附属示例。技能接口返回三个启用版本，网页和服务端均返回 HTTP 200，`git diff --check` 通过。重启前查询三个本地工作区的 Agent 会话，未发现运行中的 Agent 或子 Agent；后端已重新启动。

未运行真实 Agent 从自然语言选择模型、调用技能和创建画布的完整链路；未生成付费样片，也未验证宠物拟人动作、商品一致性、口播内容、口型或模型实际对时间的服从。技能文本和路由指令不构成程序级执行保证。需要在用户授权的模型、费用与次数范围内实际验收。

已有用户的数据目录存在旧 `petShortVideo` 时不会自动覆盖，更新工作流需安装该版本并确保专版同时可用；工作区存在同名 Skill 时会按宿主规则覆盖全局技能。回退应一并恢复工作流、宿主路由和安装副本；不涉及独立的官方 `sd25-pe`。
