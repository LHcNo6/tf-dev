# 夜间配色与快捷切换

日期：2026-11-13

## 行为与实现

Web 深色模式使用分层蓝灰色的背景、填充、边界和文字，沿用默认雾蓝强调色及现有自定义主题色。首页侧栏、画布和文档面板底部提供深色切换按钮，复用外观设置的自动保存机制；在跟随系统时点击会根据当前实际外观切换为明确的浅色或深色。设置中仍可选择跟随系统。

色板在 `apps/web/src/assets/main.scss`，切换组件在 `apps/web/src/components/themeToggle.vue`。相关维护说明见[外观与品牌](../appearanceAndBrand.md)。

## 验证与边界

- Web 类型检查和 Vite 构建通过，产物输出至 `build/web`。
- 使用本地 Web 与 Server 在 Ego Lite 中检查首页：切换后根节点为深色、按钮状态为选中，刷新后仍保持深色。
- 静态计算主要文字与背景组合对比度分别为 15.03、7.13 和 8.55；这不代表所有插件和页面均已逐项验收。
- 本机使用已安装应用内 Bun 1.4.0 启动服务，低于项目指定的 1.4.3；画布、文档面板及不同窗口尺寸的视觉和交互尚未实际验收。
