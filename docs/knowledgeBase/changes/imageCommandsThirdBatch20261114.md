# 2026-11-14：第三批图片编辑与修图指令

[返回变更索引](readme.md) · [主题维护说明](../imageCommands.md)

## 实际变化

新增 6 条中文指令：`removeObject` 清理杂物、`replaceBackground` 更换背景、`expandImage` 扩图补边、`recolor` 局部换色、`restorePhoto` 照片修复和 `styleMatch` 参考画风。均为「无限画布原创」，归入通用范围的「图片编辑」分类。当前目录共 38 条，通用 18、宠物 20。

继续按用户决定暂缓配图；新分类及卡片使用现有 Tabler 库的照片编辑图标。首批图片及第二批指令保持原样。没有调用生图、修图或其他外部模型。

## 行为与实现

- `apps/server/src/lib/imageCommands.ts`：增加目录数据，复用现有接口、单条展开、来源映射和手动调用边界。未使用的目录不会自动进入 Agent 上下文。
- `apps/web/src/pages/home/imageCommands.vue`：新增 `IconPhotoEdit` 的导入与分类映射，分类及计数沿用目录计算，未新增布局、表单或样式。
- 编辑提示词要求提供原图；删除目标、背景、扩图画幅、换色对象或颜色、主图与风格参考职责不清时，要求先补齐或确认。扩图按用户目标规格，其余默认沿用原图比例；实际规格仍受模型能力限制。
- 指令要求输出一张新图并保留原图，不自动批量生成或追加尝试。商品换色属于设计预览；遮挡区域、画外场景和未知颜色的生成属于推演，不能作为真实信息。照片修复默认保留原貌，黑白图不默认上色。
- 没有新增选区涂抹、mask、像素级区域锁定、接口、配置、依赖、工具或 Skill。缺参考先询问等要求由 Agent 按提示词执行，未增加强制入参校验。
