## 实际变化

新增 5 条中文图片指令：`petFeatureCard` 商品卖点图、`petCampaign` 活动海报、`petSizeGuide` 尺寸示意图、`petUsageGuide` 使用步骤图和 `petCompare` 商品对比图。来源均为「无限画布原创」，复用宠物范围的「宠物内容与带货」分类。当前目录共 43 条，通用 18、宠物 25，该分类共 9 条。

按用户决定继续暂缓配图；新增卡片复用分类图标，没有调用图片或其他外部模型。本批未修改 Web 源码，前几批内容及原有预览图片保持原样。

## 行为与实现

- `apps/server/src/lib/imageCommands.ts`：只在现有目录末尾加入 5 条数据，复用网页接口、来源映射、手动选择和单条展开。没有新增 Skill、工具、接口、配置或依赖。
- 卖点图需要真实商品参考、1–3 个确认卖点与确切文案；活动海报需要主题、文案及相关素材，价格、日期、优惠和参与规则只采用用户提供的内容。
- 尺寸图须提供数值、单位和部位对应，不从照片估算、不擅自换算；步骤图需要确认的 2–4 步，不推断用法、用量或效果；对比图区分 A/B 身份，对比项和值需明确，不将缺失当作零或编造优劣。
- 默认交付一张图文设计稿，缺资料先补齐，只使用提供的文字和数据，并提醒核对排字、商品细节和对应关系。不自动批量生成、制作多尺寸素材或发布。
- 上述约束由 Agent 按提示词执行，没有新增强制事实校验或固定排版工具，不承诺文字逐字准确、工程制图精度或可直接发布。
