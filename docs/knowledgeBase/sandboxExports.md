# 沙盒导出维护

## 行为

沙盒在独立的临时内存文件系统中执行命令，只有退出码为 0 才按 `exports` 顺序将指定文件写回当前工作区。每次调用的虚拟文件系统独立；未导出的文件不会保留。目标使用工作区相对路径，父目录必须已经存在，沙盒不会创建目录。默认只新建文件；明确传入 `overwrite: true` 才允许覆盖。

运行命令前检查全部导出目标的路径、重复目标及父目录；缺少父目录或父路径不是目录时，错误指出目标和父路径，调用方可先创建目录或选择已有目录。路径授权、权限错误和取消仍遵循宿主已有行为。检查不锁定目录，检查后目录变化、写入冲突或其他写回错误仍可能导致失败。

多个文件依次写回，并非事务。失败信息中的“已写回文件”列出已成功的目标；这些文件保留，处理剩余文件前应核对实际状态，避免无意覆盖或重复创建。

## 实现

[沙盒宿主](../../packages/tools/sandbox/src/host.ts)使用工作区文件接口检查父目录，执行时仍调用原有写入接口；[参数定义](../../packages/tools/sandbox/src/schema.ts)和工具说明描述目录、覆盖和部分写回约束。写入使用工作区现有路径授权与原子写入，不新增目录创建、自动重试或事务。

## 验证与边界

2026-11-10 在隔离工作区，通过实际 Server 工具上下文和沙盒进程验证：修复前缺失父目录复现 `ENOENT` 临时文件写回失败；修复后缺失目录先于命令启动报错，多个目标中任一父目录缺失时无文件写回。根目录与已有子目录导出、父路径为文件、默认不覆盖、显式覆盖、写回中途冲突及已写回清单、重复目标、越界、权限错误和执行中取消均按预期；原有文件内容保持完整。

沙盒与 Server 类型检查、构建通过；开发沙盒插件同步后与构建产物一致，服务接口返回沙盒版本 2.0.1 且无加载错误。后端进程在交付检查时已退出，重新启动后网页和后端均可访问；前端有其他浏览器连接，未重启。未验证桌面端、Windows、真实 Agent 对话调用、检查与写回之间目录被并发更改的场景；旧进程退出前的媒体任务状态无法追溯。
