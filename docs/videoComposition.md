# 合成视频节点维护

## 功能与实现

`packages/nodes/videoComposeNode` 提供视频合成画布插件，输入可混合上游 VIDEO 引用与上传素材；片段顺序、裁剪范围、音频及字幕设置随画布保存。结果为工作区内 MP4 视频引用，可连接下游节点。

选中节点时显示共享媒体工具栏，通过 `nodeSkeleton` 的下载逻辑保存当前结果，并通过播放器进入全屏；没有可读取的结果时下载按钮禁用。

桌面端使用原生另存为窗口；支持 File System Access API 的网页浏览器先选择保存位置，再读取并写入视频。其他浏览器使用浏览器自身的下载设置决定保存位置。

`composeVideo.ts` 通过节点 FFmpeg 桥接读取流与时长，裁剪各片段，将画面统一为首段偶数尺寸、30 fps、等比补黑边，并将音频统一为 48 kHz 双声道；无声片段补静音。拼接后按设置混音或替换背景音，字幕可烧录或转为 mov_text 轨道。合成前检查 libx264、AAC 及所需的字幕滤镜；失败或取消不覆盖上次结果。

素材存入 `assets/<节点 ID>/`，新输出使用唯一文件名；取消和失败清理本次未完成文件，已成功的旧文件保留以支持引用和撤销。字幕路径只接受安全字符，字幕内容须为 UTF-8 SRT 或 ASS。

## 长视频工作流与节点工具

内置 `longVideoWorkflow` 面向超过 30 秒的通用分段制作，先形成全片分段表，以节点实际模型能力和用户授权生成各段，再核对来源与顺序后合成。Seedance 提示词由已安装 `workflow` 的 PART A 管理；默认不使用上一段尾帧。严格时长方案需要裁剪时，由用户在合成节点设置裁剪范围，Agent 读回核对后执行。

合成节点提供 `node:getComposeState`、`node:setClipOrder`、`node:startCompose`、`node:waitCompose` 和 `node:cancelCompose`。顺序设置要求全部连接来源唯一、均有输出且无上传片段；启动要求完整传入来源、路径和裁剪快照。状态包含本次尝试 ID、输入快照和当前输入是否匹配；结束状态只属于当前打开节点后的尝试，旧输出不代表本次成功。合成期间输入变化会阻止提交新结果。等待最多 30 秒，取消等待不取消合成；取消合成不删除旧结果。手动上传及合成界面继续可用。

已初始化的数据目录首次启动时补入未安装的内置长视频工作流，不覆盖同名目录；开发源码修改不会自动覆盖已安装副本。运行时需实际发现 `workflow` 及其参考资料，缺失时工作流会停止受影响阶段。

安装复制发生普通异常时会清理本次创建的目录；若进程在创建目录后被强制终止，可能留下不完整目录，需检查并移除该不完整目录后再启动。

## 验证与边界

- 长视频工作流与节点工具：全仓类型检查、合成节点开发构建及产物同步、服务端构建通过；隔离数据目录带已有初始化标记时启动服务，技能接口返回长视频工作流已启用且为内置技能，节点产物接口返回成功。本地开发服务可访问并能发现技能，节点接口产物与构建文件哈希一致。运行中的开发服务仍有连接，为避免中断可能的任务未重启，现有进程的内置标记尚未刷新。
- 尚未完成新节点工具的真实画布交互、片段生成及合成端到端验收，也未验证取消、排序、失败、上游替换、不同媒体格式或真实供应商。类型检查、构建和接口可访问不代表这些行为已验证。

- 下载功能：节点类型检查、开发构建及产物同步通过；隔离画布中选中已有成片的合成节点，点击下载成功取得 MP4，`ffprobe` 读取时长为 5 秒。节点接口和网页可访问。桌面端原生保存与全屏操作尚未实测；运行中的开发服务存在连接，未重启服务以避免中断可能的任务。
- 保存位置选择：Web 类型检查和构建通过，本地网页可访问，浏览器提供 `showSaveFilePicker`；尚未实操系统保存窗口、取消和写入流程，也未验证不支持该接口的浏览器回退。现有服务有连接，未重启以免中断任务。
- 节点类型检查与开发构建通过。在隔离项目的网页中上传两段不同画幅、有声和无声的视频、短背景音及 SRT，合成后播放器显示 4 秒视频；画布保存了素材和 VIDEO 输出，`ffprobe` 检查到 H.264、AAC、mov_text 字幕轨，完整解码通过。刷新页面后素材设置恢复。
- 使用本机 FFmpeg 对裁剪、混音及替换音频分别完成合成；当前配置缺少 subtitles 滤镜，已验证烧录模式给出切换字幕轨或更换 FFmpeg 的提示。
- 交互性能修复：连线监听只比较端点与视频路径，避免 Vue Flow 连线关联的节点位置变化导致深度监听反复写入合成配置。隔离画布中实际拖动合成节点和视频节点，也验证了空预览区域的拖动；连接、移除并重新连接视频，替换上游文件；排序、裁剪输入和再次合成均可用，保存重开保留连线和配置。连接后分别移动合成节点和上游节点各 10 次，合成配置的无关写入次数均为 0；修复前移动合成节点 10 次产生 10 次无关写入。合成输出经 `ffprobe` 确认为 5 秒 H.264/AAC 视频及 mov_text 字幕轨。
- 尚未实际验证支持字幕滤镜的环境、ASS 字幕、下游连线、取消以及桌面和其他平台；字幕轨中的 ASS 样式不保证保留。各种输入编码也需要分别验证，以上交互检查不构成帧率基准测试。
