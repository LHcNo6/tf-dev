# 宠物带货提示词 Skill

Status: ready-for-agent

## 目标

用独立的 petCommercePrompt 替换宠物短视频工作流中的 Lengyi 创作规则，让宠物能够按用户意图模仿人类主播带货，形成细致的镜头、商品展示和口播计划。单独请求脚本或提示词时可直接使用，不触发媒体生成。

## 范围与实现

- 新增 `packages/skills/petCommercePrompt/SKILL.md` 和按需读取的 `references/shotGuide.md`，借鉴调研中的参考职责、调度、声音与动物接触方法，写成自包含的宠物带货规则。
- 每镜写起始状态、姿态与视线、爪子与商品接触、动作过程、终态、景别/机位/光线，以及准确台词、语气和时间。按内容选择固定机位和切镜数量，不靠增加无关动作或形容词填细节。
- 默认宠物拟人主播中文画内口播，保留身份和物种结构；用户明确选择自然动物、旁白或无声时沿用。商品外观与卖点依据实际资料，不虚构商业信息。
- petShortVideo 升级到 1.1.0，通过实际技能目录和 scope 读取新 Skill 及所属资料；删除其附带的 Lengyi 快照与模板。
- 宿主区分单独创作和画布制作入口；已初始化数据目录缺少新 Skill 时补装，同名安装版本保留。
- 现有授权、自动模式次数预算、480p 默认和最终剧本时长规则继续由工作流执行。语音和口型能力不足时说明并暂停相关执行，不静默改规格。

## 验收与边界

检查实际宿主扫描、跨技能资料读取、已初始化时补装和同名保留；同步构建及本地安装副本，验证技能接口、网页和服务。类型检查和构建只证明集成完整性，不证明模型遵循镜头、生成准确口播或稳定商品外观。

本次不增加配音/对口型工具、模型提供方、自动剪辑或批量实验，不调用付费模型生成样片。真实画布制作、语音/口型和成片质量需另行验收。
