# 通用长视频分段生成与合成工作流

Status: ready-for-agent

## Problem Statement

创作者希望根据创意、故事或剧本制作超过 30 秒的视频，但单次生成的时长受所选模型和供应商限制。手动规划片段、创建和配置多个视频生成节点、检查结果、排序并合成，操作繁琐，也容易漏掉片段、使用旧结果或按错误顺序拼接。

## Solution

提供适用于不同题材的独立长视频工作流：先规划全片，按剧情和所选模型的实际能力拆分，准备必要的共享素材，为每段创建视频生成节点，在用户确认具体生成方案后执行，并将核实有效的片段按明确顺序交给合成视频节点，输出可查看和下载的成片。

补齐合成视频节点供 Agent 使用的工具，使其能够读取片段和状态、明确设置顺序、启动合成并确认结果。继续复用已有的画布、媒体生成和 FFmpeg 合成能力。

## User Stories

1. 作为创作者，我希望用一句创意、故事或已有剧本开始，以便从现有内容进入制作。
2. 作为创作者，我希望制作任意题材的长视频，以便同一工作流适用于不同项目。
3. 作为创作者，我希望指定目标时长，以便控制成片长度。
4. 作为创作者，我希望先规划完整剧情再分段，以免遗漏或打乱内容。
5. 作为创作者，我希望根据剧情节拍切分片段，以便接缝落在合适的位置。
6. 作为创作者，我希望片段时长符合实际模型能力，以便生成请求可执行。
7. 作为创作者，我希望精确时长无法满足时看到可行组合或裁剪方案，以便决定如何调整。
8. 作为创作者，我希望每段都有编号、时长和提示词，以便查看与修改。
9. 作为创作者，我希望复用已有角色、场景和道具素材，以保持视觉一致并避免重复生成。
10. 作为创作者，我希望缺失的必要素材可以生成，以便继续制作。
11. 作为创作者，我希望各段参考实际连接的素材，以免使用错误或虚构的参考。
12. 作为创作者，我希望每段有独立视频生成节点，以便查看、调整和单独处理失败片段。
13. 作为创作者，我希望在画布上看到完整的分段与合成关系，以便理解制作进度。
14. 作为创作者，我希望在生成前看到每段模型、参数、参考、提示词及调用次数，以便判断生成方案。
15. 作为创作者，我希望在可查询时看到费用，否则明确知道费用未知，以便决定是否授权。
16. 作为创作者，我希望一次确认明确的生成方案，以便授权后连续执行该方案。
17. 作为创作者，我希望配置或参考在授权后变化时重新核对受影响调用，以免按未经确认的方案生成。
18. 作为创作者，我希望视频片段按尾帧依赖顺序生成，以便下一段从上一段结束画面开始。
19. 作为创作者，我希望失败或取消时保留已完成片段与画布，以便处理问题后继续。
20. 作为创作者，我希望不会自动重试付费生成，以免产生未授权费用。
21. 作为创作者，我希望合成按分段编号顺序执行，以免完成顺序影响剧情顺序。
22. 作为创作者，我希望缺段、重复片段或结果归属不明时停止合成，以免误交付不完整成片。
23. 作为创作者，我希望能够读取合成片段顺序和状态，以便确认实际输入。
24. 作为创作者，我希望合成失败或取消时保留上次成功结果，以免丢失已有成片。
25. 作为创作者，我希望看到实际生成的各段及成片，以便播放、检查和下载。
26. 作为创作者，我希望知道实际时长以及未检查的画面和声音，以便判断是否还需要人工验收。
27. 作为创作者，我希望保存并重开画布后保留节点、连接和合成配置，以便继续编辑。
28. 作为创作者，我希望继续已有任务时先核对实际画布和生成状态，以避免重复创建节点或重复生成。
29. 作为创作者，我希望模型不支持所需时长、素材或模式时得到具体说明，以便选择可行方案。
30. 作为创作者，我希望从第二段起使用上一段本次生成的尾帧作为首帧，以便保持片段衔接。

## Implementation Decisions

- 新增独立通用长视频 Skill；明确其与现有通用视频制作、宠物短视频工作流的适用边界。用户要求超过 30 秒的通用分段制作时采用本工作流；用户明确指定其他流程时遵循其要求并报告能力冲突。
- 长视频工作流负责全片规划、分段表、画布执行和交付。Seedance 任务沿用现有制作工作流的模型确认及提示词规则，不复制或改写其导演规则；其他模型按其真实能力和用户要求规划。
- 30 秒是工作流入口划分，不是所有模型的固定单段上限。每段的时长、分辨率组合、比例、声音、参考类型及数量以实际节点返回的模型能力为准；不静默切换模型、舍弃参考或改变明确要求。
- 明确区分严格目标时长与估算时长。严格目标无法由支持的片段时长组合满足时，展示可行组合或可执行的裁剪方案，获得用户选择后才执行；不自动缩短剧情或裁剪内容。
- 一个分段对应一个视频生成节点及完整提示词；将全片与分段表保存为可读的画布内容。连接仅传递真实素材，不作为自动调度或批准标记。已有适用素材优先复用；必要资产生成应纳入方案和授权。
- 除第一段外，每段使用上一段本次视频的有效尾帧作为首帧；明确绑定来源、实际路径、模式及提示词，严格串行生成。Seedance 的尾帧规则只在本长视频工作流内应用例外，其他工作流保持原规则。
- 媒体生成前展示待调用资产和各段的模型、完整提示词、参数、真实参考及用途、次数和可获得的费用；费用不可查询时标明未知。取得具体授权后重新读取并核对，变化影响已授权内容时仅对受影响调用重新确认。
- 使用节点提供的生成状态和独立尾帧状态识别本次终态；尾帧来源须与本次视频及当前图片输出一致。失败、取消、状态不明或关闭画布时停止相关依赖链，不自动重试付费调用。续作前重新发现节点、配置、输出及状态，不凭旧输出判断本次成功。
- 显式首帧绑定只接受实际连接的图片及其路径，模式须明确支持仅首帧。模型不支持或其他必要参考无法同时使用时暂停并由用户选择，不静默丢弃素材；未绑定的旧画布沿用原有首尾帧语义。
- 扩展现有合成节点的节点工具，提供读取当前片段、输入来源、顺序、运行状态与输出；设置完整的连接来源顺序；启动合成；以及查询或等待本次合成终态的能力。沿用宿主既有节点工具的发现和调用机制。
- 顺序设置必须验证每个待合成连接来源恰好出现一次，拒绝缺失、重复或不属于当前输入的来源；不得依靠连接完成顺序或生成完成顺序推断段号。合成前读回并比对分段表和当前有效输出，缺段、来源不明、输入变化或顺序不符时停止。
- 合成执行沿用现有实现和界面操作，向工具调用方明确区分成功、失败、取消和运行中；失败或取消不覆盖上次成功输出。不得以旧输出、启动成功或路径变化单独证明本次合成成功。
- 合成按既有行为统一视频规格、音频并重新编码；默认直接拼接，不自动添加转场或音乐。合成输出为工作区视频，可供现有播放器和下载功能使用。
- 复用现有画布与节点持久化，不引入独立调度服务、数据库迁移、新配置项或新凭据。当前画布保持可用是执行前提，不承诺关闭页面或切换画布后的后台续跑。
- 实现时更新相关维护文档及索引，记录实际行为、验证结果和未验证边界；构建并同步受影响开发产物，检查运行任务后安全重启相关本地服务并验证访问。远程推送须另获用户明确批准。

## Testing Decisions

- 以宿主画布和公开节点工具为最高可用测试接缝，验证用户可观察的输入、状态、顺序和输出，不断言内部函数调用或实现细节。仅当该接缝无法稳定覆盖关键失败情形时，在现有节点边界补充必要测试。
- 对合成节点工具覆盖完整顺序设置及读回、缺失和重复来源、无效来源、上游替换、忙碌时调用、成功、失败和取消；确认失败或取消保留旧输出，工具返回的终态与实际结果一致。
- 对工作流覆盖两段和三段生成、实际完成顺序与片段顺序不同、模型能力不匹配、严格时长不能精确组合、必要参考缺失、授权后参数变化、生成失败或状态不明，以及恢复时避免重复调用。
- 使用不同画幅、有声和无声片段进行真实合成；检查成片可播放、片段顺序、总时长和音轨，并用媒体探测及完整解码辅助验证。画面、声音和接缝质量单独人工检查。
- 保存并重新打开画布，核对节点、连接、排序、配置和输出；验证旧画布与原有手动合成操作仍可使用。
- 沿用现有合成节点维护记录及插件开发指南中的隔离画布、真实交互、构建同步和媒体探测验收先例；构建或接口可访问不等同于端到端验收。若无法使用真实供应商或桌面环境，明确记录未验证范围。

## Out of Scope

- 自动转场、自动配乐、跨段音色统一、自动重生成、批量变体及独立时间线编辑器。
- 保证生成内容、角色、动作或声音在接缝处无缝一致。
- 通用工作流引擎、新媒体生成服务、后台持久调度、自动发布和未经批准的远程推送。
- 将长视频的尾帧例外推广到其他工作流，或承诺首帧模式能与其他多模态参考同时使用。

## Further Notes

实际生成依赖所选供应商的账户、凭据和模型能力；合成依赖运行环境中的 FFmpeg 及所需编码器。素材数量和视频长度增长会增加生成费用、存储及合成耗时；不因并行执行而承诺供应商并发能力。若任一外部生成服务不可用，保留画布及已完成成果，报告受影响片段并等待用户决定。

新增 Skill 和节点工具可撤回；保留已有画布和媒体文件。Skill 源码目录不等于运行时安装目录，实施和验收需核对安装版本及实际加载结果。
