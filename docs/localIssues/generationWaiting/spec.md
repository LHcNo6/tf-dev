# 图片与视频生成等待优化

Status: ready-for-agent

## 需求与实施

用户批准将图片、视频的重复等待下沉到画布工具内部，减少语言模型读取相同上下文的次数。视频从启动计时，10分钟仍未结束时检查本次调用记录一次，再等最多5分钟；图片时间减半，5分钟检查，再等最多2.5分钟。成功或失败立即返回。

运行中的图片、视频调用记录提前创建并与生成编号关联；等待期间按同一编号查询。到总上限只结束等待，保留任务及已完成素材，报告待续，不自动取消、重提交或重置时间。关闭画布后的后台调度、音频、尾帧和合成等待不包含在本次范围。

已实现接口、关键路径和实际验证结果见[维护说明](../../knowledgeBase/generationWaiting.md)。不新增测试模块；真实模型验证须有对应批次的算力授权。
