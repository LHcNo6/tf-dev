## 1. 官方推荐的写法

### 基础结构

官方推荐灵活组合：**主体 + 动作或事件 + 场景与环境 + 视觉风格 + 运镜或切镜 + 声音**。主体和动作构成内容基础，其余按需求使用。先概括主要过程，只对关键动作加具体细节，避免重复描述；视觉术语应能对应看得见的效果，而非依赖抽象品质词。[来源：官方撰写指南，第 1.1 节](https://bytedance.larkoffice.com/docx/OsiUdR1OxoDqvnxsK8LczYx7nPd#doxcnFWzdQVaH8VcFqGIPQOy8nd)

官方撰写指南建议可调的画幅、总时长、分辨率等在生成页面或接口设置；创作正文中的事件时间区间用于描述节奏，是另一类信息。不要将正文里的“24 秒”当作节点参数已经设置成功，也不要把某个模板字段当作唯一合法格式。

### 参考素材

按实际上传顺序逐项说明编号与职责，例如：图片负责宠物身份、另一张图负责商品外观、场景图负责桌面布局；音频用于音色还是完整台词应单独说明。多角色按人物逐个绑定图像和音色，不只依赖图上的名字。素材已准确表达动作和运镜时，官方建议引用其需要继承的内容，避免重复写一套可能冲突的动作。[来源：方舟指南“参考类（多素材映射）”](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)

官方方舟资料列出的单次输入上限为图片最多 30 张、视频最多 10 段且视频合计最多 30 秒、音频最多 10 段且音频合计最多 30 秒，所有参考合计最多 50 份。这是方舟指南中的上限，不是建议把素材填满，也不证明其他供应商或当前节点有相同限制。建议范围和硬上限应分开看。

### 阶段、镜头与时间戳

普通叙事优先用连续阶段组织；每个阶段描述一个主要状态变化及可见终态。需要控制关键交接、转场或节奏时，可按镜头编号或整数秒时间区间描述；区间连续、不重叠。时间段是事件预算，不是保证精确剪辑的帧点；太空模型可能自行发挥，太满可能漏剧情或产生过多切镜。官方不建议用时间戳控制“一秒内摇头三次”一类高频动作。[来源：官方撰写指南，第 2.2 节](https://bytedance.larkoffice.com/docx/OsiUdR1OxoDqvnxsK8LczYx7nPd#doxcn0G15NytahPYQxzy9xmFkFf)

这与现有宠物 Skill 的起点→动作→终态原则基本一致。其 [示例](../../packages/skills/petCommercePrompt/references/shotGuide.md) 对对白写有 `0.8–4.8` 秒等小数区间；官方明确推荐以 1 秒为基本单位，不能假设这些小数能够被精确执行。后续适配可保留用户明确指定的小数作为创意要求，同时将精确度标为待验证；自行编排时优先使用整数秒或阶段，不把估算写成保证。

### 台词、声音和字幕

官方允许自然语言；需要区分类型时推荐 `()` 表示音乐、`<>` 表示音效、`{}` 表示台词、`【】` 表示字幕。这些符号是帮助区分的写法，并非必须使用的硬语法。台词明确说话者与语言；需要控制口音、语气时一并写明。对于画外音，说明声源在画外、是否需要画内主体做口型。[来源：官方撰写指南，第 1.3 节](https://bytedance.larkoffice.com/docx/OsiUdR1OxoDqvnxsK8LczYx7nPd#doxcnIDKnNQ26xVxnQH1ABN5g9f)

官方方舟指南允许分别约束对白、环境音、音效、背景音乐和字幕。宠物口播时可写“保留宠物中文对白及轻微室内声，不要背景音乐”，不应将“不要 BGM”写成“没有声音”。若不希望字幕，官方建议不要在台词后反复复述词语并分别对具体词追加表情或动作；可写“角色台词（情绪）：内容”。参考视频自身含字幕也可能带入，官方明确说明无字幕目前无法完全保证。[来源：方舟指南“字幕约束不生效”](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)

画内口播应按实际目标写清说话者、语言、完整台词、声音特征、与表情动作的关系；其他角色在听时保持安静。参考音频可能用于音色或台词，须说明用途并确认实际接口支持。**音频驱动时不应无条件套用“一定引用音频但绝不写原文”**：现有通用宠物 Skill 与本机优化器采用此策略，但本次所查官方指南支持参考音色、台词等不同用途，未证实一个通用规则适用于所有供应商；应按任务和接口明确区分，保留审阅稿中的台词。

### 字数和失败处理

官方指南作者在其公开文档评论中表示没有经验证的统一最佳字数，复杂任务需清楚描述更多信息，简单任务可以简洁；字数与效果不是线性关系。评论提到方舟 API 15,000 字符上限，应以当前接口限制为准，而不是把本机旧 `seedance` Skill 宣称的“2000 字”为 2.5 普遍硬上限。Toonflow 当前安泰信源码限制 `prompt.length <= 15000`，这只说明本地适配器限制，不证明远端实际表现或所有供应商限制。

官方 FAQ 已列出字幕约束失效、字幕继承、文字错字、角色/音色错配、复杂任务不稳定等问题。商品包装文字、标志和颜色要求精确时，参考图可帮助约束但不能保证准确；若最终文字必须可交付，应考虑提供可核实商品素材、人工复核或后期合成。复杂人物/商品接触与长句同时失败时，先区分失败原因，再考虑简化动作、分镜、重新生成或后期处理；重复生成须符合用户的实际授权和预算。

## 2. 与 Toonflow 当前实现的关系

截至调研日，源码中 [petCommercePrompt](/Users/llx/project/toonflow-dev/packages/skills/petCommercePrompt/SKILL.md) 为 1.0.1，已具备大部分通用内容：拟人表演、商品事实、参考职责、逐镜动作终态和对白。后续新增的 [Seedance 2.5 版](/Users/llx/project/toonflow-dev/packages/skills/petCommercePromptSd25/SKILL.md) 及工作流接入见[变更记录](../knowledgeBase/changes/petCommercePromptSd2520261111.md)。调研提出的专项内容是：

1. 增加可选的 Seedance 2.5 模型适配：阶段优先、必要时使用整数秒时间轴；不把“每镜必须有小数秒对白”当作模型保证。
2. 根据用户实际需要选择自然语言或官方推荐的音效/对白标记；针对“只要对白、不要音乐”分别写声音类别。字幕规避措施针对实际需求使用，不自动添加一整套否定词。
3. 引用素材时明确职责，并处理 Toonflow 内部引用到供应商标记的实际转换；保留画面、台词和商品身份的事实来源。
4. 区分“生成画内台词”“参考音频音色”“使用参考音频台词”“画外旁白”，不能把一种音频约定套到全部任务。
5. `sd25-pe` 若被引入，仅作为模型侧提示词优化候选；它面向已有输入的整理，宠物主播创意、销售话术及商品事实仍由宠物带货创作层负责。其本机版本对“用户只给说话意图、不提供原句”倾向不补写对白，这与用户明确要求代写带货口播时的上游任务不同，不能简单全量替换现有创作 Skill。

源码中的[安泰信适配器](../../packages/providers/src/media/antaixin.ts)声明 `seedance-2.5-video` 支持 4–30 秒、480p/720p/1080p、可选声音及多参考；它把视频节点的 `{{ref N}}` 根据实际 `referenceOrder` 映射成 `图片N`、`视频N` 或 `音频N` 文本后提交。这里是 **Toonflow 源码的行为**，不等于本次验证了已安装供应商版本、远端模型、账户配额或口型质量。视频/音频参考需要可访问的公网 URL；是否能在当前节点和供应商完成具体任务，应现场检查。

本地适配器还在用户提供参考视频时长信息且选择固定输出时长的情况下，检查“参考视频总时长 + 输出时长 ≤ 30 秒”。这比官方指南中单独列出的“参考视频合计 ≤ 30 秒”更严格；两者作用域不同，使用本地接入时必须以实际适配器约束为准，不能直接按官方通用表推断本地可执行。不要为规避冲突静默修改用户时长。

## 3. 示例：宠物主播介绍玩具

这是依据官方结构**自行编写的示意草稿**，未生成或评估效果。假设用户已提供宠物照片、商品照片、场景图，并确认玩具“轻推会摇晃”；画布实际连接顺序须在生成前核实。假设节点中 `{{ref 1}}`、`{{ref 2}}`、`{{ref 3}}` 分别对应宠物、商品、场景，以下只是示范，不能照抄编号。建议节点另设 14 秒、竖屏、声音开启，且先核实所选模型/供应商支持该组合。

```text
创作目标：一只宠物猫模仿主播，在明亮的桌面直播场景中介绍一个会摇晃的猫玩具，语气轻松亲切。

参考职责：{{ref 1}} 用于猫的脸型、毛色和身份；{{ref 2}} 用于玩具的真实外观和颜色；{{ref 3}} 用于桌面、背景布局和光线。保持同一只猫、同一个玩具与相同主光方向。

0–4秒：平视中近景，镜头固定。猫坐在桌后，玩具直立在画面右侧。猫看向镜头，抬左前爪朝玩具示意，再把爪子放回桌面。猫用轻快的中文说：{今天给大家看看这个玩具。} 说完自然闭嘴。

4–9秒：切到能看清猫前爪和玩具底部的中景。猫看向玩具，用左前爪轻推玩具一次，爪子回到桌面；玩具在桌上摇晃，摆幅逐渐减小。猫的中文台词（惊喜）：{轻轻一推，它就摇起来啦。} 说完闭嘴。

9–14秒：镜头回到猫与玩具同框。玩具逐渐停稳，猫看一眼玩具，再看回镜头，轻轻点头，最后保持坐姿和商品位置。

声音：猫是唯一说话者，声音在不同镜头保持一致；保留台词和轻微室内环境声，以及与玩具接触相符的轻声；不要背景音乐和字幕。
```

**验收要看实际成片**：猫的身份和爪子是否稳定、爪子与玩具是否真实接触、商品外观是否保持、台词有无漏字或改写、是否为猫的画内声音、口型与说话节奏是否大致对应、是否出现意外字幕或背景音乐。官方未在本次查阅的资料中保证宠物说中文的口型表现。
