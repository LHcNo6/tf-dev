# Toonflow 本机修复总结

本机 Toonflow 2.0.8。安泰信适配器已升级并安装到 4.1.1；图片来源 URL 后端补丁和本次滚轮快捷键补丁均已安装。未提交或推送代码。

## 图片生成、视频生成与连线传图

- 图片生成结果继续保存本地，同时私下记录原始下载 URL 与内容摘要。生图节点连到视频节点时，原始 URL 尚可用且内容校验一致就直接复用；旧图、导入图或链接失效时，上传到安泰信自己的素材接口，取得 URL 后提交视频任务。
- 大于 1 MiB 的本地视频参考图默认制作 WebP 传输副本，最长边 2048、质量 90；原图保留，可关闭压缩。已有有效原始 URL 的图片直接复用链接。
- 修正引用顺序映射、首尾帧角色和模式校验；支持文生视频、多图参考、首尾帧、视频编辑/延长，以及文档中的时长、分辨率、比例、生成音频、种子和视频水印设置。
- 生图支持最多 10 张参考图、1K/2K、1–4 张输出；视频混合参考支持最多 30 图、10 视频和 10 音频。没有已知公网来源的视频/音频，需要补充公网 URL。
- 修正 Seedream 拒绝 `watermark:false` 的兼容问题：图片请求完全省略水印字段。
- 524 和其他上游错误改为简明提示；未取得任务 ID 时不自动重提付费任务，避免重复扣费。上游服务自身的稳定性仍取决于安泰信。

此前验收记录：52 项离线测试、484 条断言全部通过。经授权完成真实文生图 1 张，以及“三张参考图 → 4 秒视频”生成：新图原始 URL 直接复用，视频请求内 Base64 参考数为 0；成片 480×854、约 4.04 秒、无音轨。首尾帧、图片多参考编辑、视频编辑和延长等其他模式通过离线测试，未逐项额外付费生成。

边界：图片接口未提供独立宽高比参数，提示词构图不能保证严格像素比例；本次真实图片为 1024×1024。当前生图节点连线只输出多张生成结果中的第一张，其余结果保存在资产目录；需要多图连线时使用多个生图节点。

详细功能和配置见 [适配器使用与验证说明](toonflow-4.1/使用与验证说明.md)，真实结果见 [真实生成验收说明](toonflow-4.1/real-acceptance/真实验收说明.md)。

## Option（Alt）＋滚轮与快捷键编辑

已将当前滚轮缩放绑定设为 `Alt`，并把 macOS 的默认值同步改为 `Alt`，因此“恢复默认”也会使用 Option。界面显示 `Option (Alt)`；其他平台默认值仍为 Ctrl。

点击编辑没有反应的根因已经复现：macOS WebKit 点击录制按钮后，按钮没有自动取得焦点；后续按键送不到按钮的录制处理器。修改点击处理器，显式聚焦按钮后开始录制。录制、手动填写、取消绑定、无需按键、Esc/失焦取消和恢复默认均保留。

验证：

- 原版 WebKit 测试失败：点击后 `aria-pressed=true`，但 `document.activeElement` 不是按钮；按 Option 后仍显示“请按快捷键…”。仅补焦点即可录制成功。
- 安装后的 WebKit、Chromium 实际界面验证通过：点击录制、修饰键组合、普通快捷键、手动编辑、自动保存、重载、恢复默认、清除绑定、无需按键和重新绑定。
- 独立启动已安装应用，在实际 VueFlow 画布上验证：Option＋滚轮缩放；普通滚轮平移；物理 Control＋滚轮不触发画布缩放；触控板 pinch 事件仍可缩放。独立后端实际保存并在重载后保留 Option 配置。
- 保留了原有滚轮/捏合处理器；Safari 原生手势路径另由真实处理器夹具验证。自动化测试不代表已用物理触控板逐项人工验收。
- 已通过主实例设置 API 写入 Option，并读取 API 和磁盘确认。其余设置保持一致；此前后端、来源模块、适配器校验和保持一致。没有改写用户项目，没有新增生成请求。独立测试进程已停止。

**请保存当前画布，正常退出并重新打开 Toonflow 一次，以加载已更新的前端文件。** 已打开窗口仍可能缓存旧版脚本。本次没有强制关闭你的应用，也没有修改 macOS 系统辅助功能设置。

之后在“设置 → 常规配置 → 画布快捷键”点击“滚轮缩放”的键帽，按下并松开 Option 即可录制；也可选择“手动填写”，输入 `Alt` 后回车或移开焦点保存。

快捷键补丁、校验记录、验证脚本和回滚说明位于 [toonflow-wheel](toonflow-wheel/修复说明.md)。应用升级可能覆盖本机修改。

## 图片与视频节点参数显示及调参可用性（2026-10-30）

已安装两个节点的界面补丁。原问题是显示不同步：视频摘要忽略了已保存的高级画幅覆盖，图片摘要把生成数量写死为 1 张。现在摘要、面板当前设置与选中高亮均反映当前值；视频比例、分辨率、时长、模式、音频及原有高级设置保留。Seedance 的七种视频比例可直接在主区域选择；图片显示真实生成张数。

修复长面板超出窗口及高级下拉框误触发外部关闭，增加滚动、置顶当前设置、收起按钮和 Esc 退出。选择沿用自动保存，不需要额外点击保存。

WebKit 对已安装版本、Chromium 对同一最终候选代码的真实界面验证通过，覆盖参数修改、请求序列化、画布落盘及重载。生成请求在浏览器边界被截获，没有新增付费任务。此前后端、URL 来源模块、安泰信 4.1.1 和 Option 滚轮文件校验和保持一致；原用户画布未被测试改写。

保存画布后请正常重启应用加载更新。详细说明与回滚见 [参数修复说明](toonflow-params/修复说明.md)。
